# Report format (all personas)

```
# <Persona name> — report

## Bottom line
<2–3 sentences: your overall judgement through this lens.>

## Major issues
1. **<label>** (<location>) — <what is wrong, why it matters to the
   evaluator/referee> → Fix: <smallest sufficient change>
   Type: defect | concern

## Minor issues
- (<location>) <issue> → <fix>

## Answers to the brief's open questions
- <question>: <answer>

## Strengths to preserve
- <what works and should not be lost in revision>

## Checks I could not do
- <claims needing verification, data you could not see, etc.>
```

In `ideas` mode, replace "Major/Minor issues" with "Directions" (2–3, each
with rationale, main risk, what it would take) and "My pick".

Typical length: 400–900 words. More is not better.
