### AlphaFold Data Input and Feature Generation
The AlphaFold inference pipeline begins by transforming raw protein sequences into a comprehensive set of features that the neural network model can consume. This process involves parsing various biological data formats, generating Multiple Sequence Alignments (MSAs), identifying and featurizing structural templates, and orchestrating these steps for both single-chain (monomer) and multi-chain (multimer) predictions.

The [`DataPipeline`](https://github.com/google-deepmind/alphafold/alphafold/data/pipeline.py#L123) classes in [`/google-deepmind/alphafold/alphafold/data/pipeline.py`](https://github.com/google-deepmind/alphafold/alphafold/data/pipeline.py) and [`/google-deepmind/alphafold/alphafold/data/pipeline_multimer.py`](https://github.com/google-deepmind/alphafold/alphafold/data/pipeline_multimer.py) are responsible for orchestrating feature generation. For both monomers and multimers, the process starts by accepting protein sequences, typically in FASTA format. These sequences are first converted into basic sequence-level features such as amino acid types and residue indices.

A crucial step in feature generation is creating MSAs, which represent evolutionary information. This involves running external bioinformatics tools like Jackhmmer and HHblits against large protein sequence databases. These tools search for homologous sequences and align them, providing rich evolutionary context for each residue in the target protein. The output of these tools, often in formats like Stockholm or A3M, is then parsed and consolidated into a unified MSA feature set. The directory [`/google-deepmind/alphafold/alphafold/data/tools`](https://github.com/google-deepmind/alphafold/alphafold/data/tools) contains Python wrappers for these external tools, handling their execution, temporary file management, and output parsing. For more details on how these external tools are integrated, see [External Bioinformatics Tool Wrappers](#alphafold-data-management-and-external-tool-integration-external-bioinformatics-tool-wrappers).

Simultaneously, the pipeline searches for known protein structures that are similar to the target sequence, using tools like HHsearch or HMMsearch. These "template hits" provide valuable structural information that can guide the prediction process. Once identified, these template hits are processed to extract relevant structural features, including atomic coordinates and their masks. This featurization involves parsing mmCIF files ([`/google-deepmind/alphafold/alphafold/data/mmcif_parsing.py`](https://github.com/google-deepmind/alphafold/alphafold/data/mmcif_parsing.py)), aligning template sequences to the query, and ensuring the structural integrity of the templates. The featurization process also includes pre-filtering steps based on criteria such as template release dates and sequence similarity to ensure only high-quality templates are used.

For multimer predictions, the process introduces additional complexities. Each chain in a multimeric complex is initially processed to generate its individual features. Then, a sophisticated MSA pairing logic is applied, particularly within [`/google-deepmind/alphafold/alphafold/data/msa_pairing.py`](https://github.com/google-deepmind/alphafold/alphafold/data/msa_pairing.py) and [`/google-deepmind/alphafold/alphafold/data/feature_processing.py`](https://github.com/google-deepmind/alphafold/alphafold/data/feature_processing.py). This step aims to identify and align homologous sequences across different protein chains within the complex, which is critical for modeling inter-chain interactions. Chains are grouped by sequence to identify homomers (identical subunits), and unique identifiers ([`entity_id`](https://github.com/google-deepmind/alphafold/server/example.json#L34), [`sym_id`](https://github.com/google-deepmind/alphafold/alphafold/data/msa_pairing.py#L54), [`asym_id`](https://github.com/google-deepmind/alphafold/alphafold/model/model.py#L49)) are assigned to residues to distinguish between different chains and their symmetry relationships. After pairing, the features from all chains are merged and cropped to manage computational resources, resulting in a single feature dictionary that represents the entire multimeric complex.

Throughout this entire process, various biological file formats are parsed by [`/google-deepmind/alphafold/alphafold/data/parsers.py`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py) to extract the necessary information. This includes parsing FASTA for sequences, Stockholm and A3M for MSAs, HHR for template search results, and mmCIF for detailed structural data. The parsing modules provide structured data representations such as [`Msa`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py#L30) for multiple sequence alignments and [`TemplateHit`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py#L62) for template search results, which are then used in downstream featurization steps.
