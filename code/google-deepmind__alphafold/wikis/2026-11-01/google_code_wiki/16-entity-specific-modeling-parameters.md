### Entity-Specific Modeling Parameters
AlphaFold Server job submissions, defined in the [`README.md`](https://github.com/google-deepmind/alphafold/pyproject.toml#L28) file within [`/google-deepmind/alphafold/server`](https://github.com/google-deepmind/alphafold/server), require a [`sequences`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py#L33) list that details the molecular entities to be modeled. Each entry in this list specifies the type of entity and its associated parameters. This enables the server to handle diverse molecular inputs for structural predictions.

For [`proteinChain`](https://github.com/google-deepmind/alphafold/server/README.md#L52) entities, detailed specifications can include the primary sequence, along with optional [`glycans`](https://github.com/google-deepmind/alphafold/server/README.md#L80) (specifying [`residues`](https://github.com/google-deepmind/alphafold/README.md#L417) and [`position`](https://github.com/google-deepmind/alphafold/alphafold/data/mmcif_parsing.py#L64)) and [`modifications`](https://github.com/google-deepmind/alphafold/LICENSE#L27) (using [`ptmType`](https://github.com/google-deepmind/alphafold/server/README.md#L92) and [`position`](https://github.com/google-deepmind/alphafold/alphafold/data/mmcif_parsing.py#L64) based on CCD codes). Users can also define the [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334) for multiple copies of the protein chain, indicate whether to [`useStructureTemplate`](https://github.com/google-deepmind/alphafold/server/README.md#L70), and set a [`maxTemplateDate`](https://github.com/google-deepmind/alphafold/server/README.md#L70) (an ISO 8601 date string) to filter PDB templates. Additionally, [`unpairedMsa`](https://github.com/google-deepmind/alphafold/server/README.md#L111) can be provided in A3M format for multiple sequence alignment, and custom structural [`templates`](https://github.com/google-deepmind/alphafold/README.md#L133) can be included as a list of dictionaries containing [`mmcif`](https://github.com/google-deepmind/alphafold/README.md#L160) content, [`queryIndices`](https://github.com/google-deepmind/alphafold/server/README.md#L122), and [`templateIndices`](https://github.com/google-deepmind/alphafold/server/README.md#L124) for residue mapping.

Single-stranded [`dnaSequence`](https://github.com/google-deepmind/alphafold/server/README.md#L53) and [`rnaSequence`](https://github.com/google-deepmind/alphafold/server/README.md#L54) entities require specifying their respective [`sequence`](https://github.com/google-deepmind/alphafold/alphafold/data/pipeline_multimer.py#L41) (A, T, G, C for DNA; A, U, G, C for RNA) and [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334) for copies. Both can include optional [`modifications`](https://github.com/google-deepmind/alphafold/LICENSE#L27) with a [`modificationType`](https://github.com/google-deepmind/alphafold/server/README.md#L194) (using CCD codes) and [`basePosition`](https://github.com/google-deepmind/alphafold/server/README.md#L197). Double-stranded DNA modeling is achieved by providing two [`dnaSequence`](https://github.com/google-deepmind/alphafold/server/README.md#L53) entries, one for the forward and one for the reverse complement strand.

Finally, [`ligand`](https://github.com/google-deepmind/alphafold/server/README.md#L55) and [`ion`](https://github.com/google-deepmind/alphafold/server/README.md#L56) entities are specified by their respective [`CCD code`](https://github.com/google-deepmind/alphafold/server/README.md#L93) and [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334), allowing for the inclusion of small molecules and ions in the modeling process. These detailed entity-specific parameters provide granular control over the AlphaFold modeling task, enabling the prediction of complex biological assemblies. For a general overview of the JSON request schema, refer to [AlphaFold Server JSON Request Schema](#alphafold-server-job-submission-alphafold-server-json-request-schema).
