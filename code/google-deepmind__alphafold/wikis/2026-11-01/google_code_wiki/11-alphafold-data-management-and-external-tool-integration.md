## AlphaFold Data Management and External Tool Integration
AlphaFold's operation relies on extensive biological databases and the integration of various bioinformatics tools for feature generation. The system manages access to the AlphaFold Protein Structure Database and orchestrates the use of external tools through Python wrappers.

The AlphaFold Protein Structure Database, documented in [`/google-deepmind/alphafold/afdb/README.md`](https://github.com/google-deepmind/alphafold/afdb/README.md), provides a vast collection of predicted protein structures. This database is hosted on Google Cloud Public Datasets and is accessible through several methods. Users can perform bulk downloads of the entire dataset or obtain specific subsets. For targeted data retrieval, metadata querying via BigQuery allows for filtering based on criteria like organism or confidence scores, enabling the creation of custom download manifests. Each protein entry typically includes atomic coordinates in CIF format and confidence metrics such as pLDDT and Predicted Aligned Error (PAE). [AlphaFold Protein Structure Database Access and Querying](#alphafold-data-management-and-external-tool-integration-alphafold-protein-structure-database-access-and-querying) provides additional details on accessing this resource.

To prepare input features for its models, AlphaFold integrates with several third-party bioinformatics tools. This integration is handled by Python wrappers located in [`/google-deepmind/alphafold/alphafold/data/tools`](https://github.com/google-deepmind/alphafold/alphafold/data/tools). These wrappers manage the execution of command-line tools like [`HHblits`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L79), [`HHsearch`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L84), [`Jackhmmer`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L31), [`hmmbuild`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmbuild.py#L27), [`hmmsearch`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmsearch.py#L29), and [`Kalign`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L36). The wrappers abstract the complexities of subprocess management, temporary file handling, and output parsing, providing a standardized interface for the AlphaFold pipeline. For instance, [`HHBlits`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhblits.py#L32) ([`/google-deepmind/alphafold/alphafold/data/tools/hhblits.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhblits.py)) performs protein sequence database searches to generate multiple sequence alignments (MSAs), while [`Jackhmmer`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L31) ([`/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py)) facilitates homology searches, with support for streamed database queries to manage large datasets efficiently. Similarly, [`Kalign`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L36) ([`/google-deepmind/alphafold/alphafold/data/tools/kalign.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py)) is used for multiple sequence alignment. Utility functions within this directory, such as [`tmpdir_manager`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/utils.py#L25) ([`/google-deepmind/alphafold/alphafold/data/tools/utils.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/utils.py)), ensure proper cleanup of temporary files and directories generated during tool execution. Further details on these wrappers can be found in [External Bioinformatics Tool Wrappers](#alphafold-data-management-and-external-tool-integration-external-bioinformatics-tool-wrappers).
