### AlphaFold Model Architecture and Execution
The AlphaFold model architecture processes protein features and iteratively refines a protein's predicted 3D structure. The core neural network functionality is orchestrated by [`AlphaFold`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L289) modules, defined in [`/google-deepmind/alphafold/alphafold/model/modules.py`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py) for monomer prediction and [`/google-deepmind/alphafold/alphafold/model/modules_multimer.py`](https://github.com/google-deepmind/alphafold/alphafold/model/modules_multimer.py) for multimer prediction. These modules coordinate iterative prediction steps ([`AlphaFoldIteration`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L134)) and manage the overall flow from initial feature embedding through to final structure prediction.

The [`AlphaFoldIteration`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L134) is a single pass through the network, consisting of an [`EmbeddingsAndEvoformer`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py#L857) component and a [`StructureModule`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L465). The [`EmbeddingsAndEvoformer`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py#L857) handles the initial embedding of input features and subsequent processing through the Evoformer stack. Within the Evoformer, a key component is the [`EvoformerIteration`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L1751), which refines sequence and multiple sequence alignment (MSA) representations using various attention mechanisms, such as [`InvariantPointAttention`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L37), [`MSAColumnAttention`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L858), and [`TriangleMultiplication`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py#L763).

The [`StructureModule`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L465) (defined in [`/google-deepmind/alphafold/alphafold/model/folding.py`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py) for monomer and [`/google-deepmind/alphafold/alphafold/model/folding_multimer.py`](https://github.com/google-deepmind/alphafold/alphafold/model/folding_multimer.py) for multimer) takes the Evoformer's outputs and iteratively refines residue positions and orientations. This involves [`InvariantPointAttention`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L37) for geometry-aware attention, [`FoldIteration`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L290) to update hidden representations and affine transformations, and [`MultiRigidSidechain`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L989) to predict side-chain atom positions. The output of the [`StructureModule`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L465) is a trajectory of residue [`affine`](https://github.com/google-deepmind/alphafold/alphafold/model/modules.py#L1244) transformations and sidechain predictions, which are then converted into full atom positions.

The model's execution is managed by the [`RunModel`](https://github.com/google-deepmind/alphafold/alphafold/model/model.py#L72) class in [`/google-deepmind/alphafold/alphafold/model/model.py`](https://github.com/google-deepmind/alphafold/alphafold/model/model.py). This class loads pre-trained parameters (via [`/google-deepmind/alphafold/alphafold/model/data.py`](https://github.com/google-deepmind/alphafold/alphafold/model/data.py)), processes input features using [`features.np_example_to_features`](https://github.com/google-deepmind/alphafold/alphafold/model/model.py#L139), and executes the model's forward pass. After the initial structure prediction, [`RunModel`](https://github.com/google-deepmind/alphafold/alphafold/model/model.py#L72) also calculates confidence metrics like predicted Local Distance Difference Test (pLDDT) and Predicted TM-score (pTM), which are crucial for assessing prediction quality.

Model configurations are managed by [`/google-deepmind/alphafold/alphafold/model/config.py`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py), which defines base settings for monomer and multimer models and applies specific modifications through [`CONFIG_DIFFS`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py#L55) and [`MODEL_PRESETS`](https://github.com/google-deepmind/alphafold/alphafold/model/config.py#L30). The [`BaseConfig`](https://github.com/google-deepmind/alphafold/alphafold/model/base_config.py#L132) class in [`/google-deepmind/alphafold/alphafold/model/base_config.py`](https://github.com/google-deepmind/alphafold/alphafold/model/base_config.py) provides a framework for creating hierarchical, type-annotated configurations that can be frozen to prevent accidental modification, ensuring reproducibility.

Geometric operations are fundamental to the [`StructureModule`](https://github.com/google-deepmind/alphafold/alphafold/model/folding.py#L465) and are handled by the [`/google-deepmind/alphafold/alphafold/model/geometry`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry) directory. This includes [`Vec3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L33) for vectors, [`Rot3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py#L33) for rotation matrices, and [`Rigid3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rigid_matrix_vector.py#L32) for rigid transformations, all designed for efficient, batched computations with JAX. The [`lddt`](https://github.com/google-deepmind/alphafold/alphafold/model/lddt.py#L19) function in [`/google-deepmind/alphafold/alphafold/model/lddt.py`](https://github.com/google-deepmind/alphafold/alphafold/model/lddt.py) computes an approximate lDDT score to compare predicted and true structures based on distance matrices.

The [`layer_stack`](https://github.com/google-deepmind/alphafold/alphafold/model/layer_stack.py#L212) utility in [`/google-deepmind/alphafold/alphafold/model/layer_stack.py`](https://github.com/google-deepmind/alphafold/alphafold/model/layer_stack.py) provides a mechanism for stacking multiple instances of a Haiku function, allowing each instance to have independent parameters. This enables the creation of deep neural networks or iterative processes with non-shared weights. For large inputs, sharded computation utilities in [`/google-deepmind/alphafold/alphafold/model/mapping.py`](https://github.com/google-deepmind/alphafold/alphafold/model/mapping.py) allow processing in smaller chunks, managing memory trade-offs.
