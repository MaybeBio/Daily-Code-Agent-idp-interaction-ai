### Common Data Structures and Confidence Metrics
The AlphaFold pipeline utilizes a set of foundational data structures and constants to represent and manipulate protein information, alongside utilities for assessing prediction confidence. The core data structure for managing protein geometries is the [`Protein`](https://github.com/google-deepmind/alphafold/alphafold/common/protein.py#L65) dataclass, defined in [`/google-deepmind/alphafold/alphafold/common/protein.py`](https://github.com/google-deepmind/alphafold/alphafold/common/protein.py). This dataclass encapsulates critical structural data such as atom positions, amino acid types, atom masks, residue and chain indices, and B-factors. It includes utilities for parsing standard protein formats like PDB and mmCIF strings, as well as for serializing internal [`Protein`](https://github.com/google-deepmind/alphafold/alphafold/common/protein.py#L65) objects back into these formats. This allows for seamless integration with existing bioinformatics tools and databases.

Residue-specific biochemical constants and properties are centralized in [`/google-deepmind/alphafold/alphafold/common/residue_constants.py`](https://github.com/google-deepmind/alphafold/alphafold/common/residue_constants.py). This module provides detailed information crucial for structural modeling, including definitions for torsion (chi) angles, relative atom positions within rigid groups, and mappings between various residue and atom naming conventions. It also includes functions for operations such as one-hot encoding of amino acid sequences, which is a common requirement for machine learning models. The constants defined here ensure consistency and accuracy in structural calculations throughout the AlphaFold system.

To evaluate the quality and reliability of predicted protein structures, AlphaFold incorporates functions for calculating key confidence metrics. The [`/google-deepmind/alphafold/alphafold/common/confidence.py`](https://github.com/google-deepmind/alphafold/alphafold/common/confidence.py) module is dedicated to computing and formatting these metrics. It generates per-residue Predicted Local Distance Difference Test (pLDDT) scores, which indicate the confidence of each residue's predicted position. It also calculates the Predicted Aligned Error (PAE), providing a measure of global accuracy and relative positional error between residue pairs. Additionally, this module computes predicted TM-scores, which evaluate the topological similarity between predicted and (hypothetical) true structures. These metrics are formatted into JSON outputs, facilitating their use in downstream analyses and visualizations. Furthermore, to ensure proper attribution and standardized data sharing, AlphaFold-specific metadata, including licensing, authorship, citation details, and model quality metrics like global pLDDT, are embedded into mmCIF files using the functionality in [`/google-deepmind/alphafold/alphafold/common/mmcif_metadata.py`](https://github.com/google-deepmind/alphafold/alphafold/common/mmcif_metadata.py). This process enriches the structural data with important contextual information.
