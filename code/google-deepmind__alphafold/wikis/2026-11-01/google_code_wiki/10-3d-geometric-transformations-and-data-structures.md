### 3D Geometric Transformations and Data Structures
The AlphaFold inference pipeline uses a set of foundational 3D geometric operations and data structures to efficiently represent and manipulate protein structures. These structures are designed for batched computations and JAX compatibility, supporting operations essential for predicting protein tertiary and quaternary structures.

The core geometric primitives include:

*   **[`Vec3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L33) for Vectors:** Represented by the class in [`/google-deepmind/alphafold/alphafold/model/geometry/vector.py`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py), [`Vec3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L33) handles 3D vectors. This class supports common vector arithmetic such as addition, subtraction, scalar multiplication, dot products, and cross products. It also provides functionality for calculating vector norms, normalizing vectors, and determining dihedral angles between sets of four points. The implementation utilizes a "Struct of Arrays" (SoA) approach for performance with JAX, storing [`x`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L45), [`y`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L46), and [`z`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L47) components as separate arrays.

*   **[`Rot3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py#L33) for Rotation Matrices:** Defined in [`/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py), [`Rot3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py#L33) encapsulates 3x3 rotation matrices. It offers methods for inverting rotations (transposing the matrix), applying rotations to points, and composing rotations. The class also includes various constructors to create rotation matrices from different representations, such as two vectors or quaternions. Like [`Vec3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L33), it uses an SoA pattern, storing each element of the 3x3 matrix individually for JAX efficiency.

*   **[`Rigid3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rigid_matrix_vector.py#L32) for Rigid Transformations:** The [`/google-deepmind/alphafold/alphafold/model/geometry/rigid_matrix_vector.py`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rigid_matrix_vector.py) file introduces [`Rigid3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rigid_matrix_vector.py#L32), which combines a [`Rot3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/rotation_matrix.py#L33) (rotation) and a [`Vec3Array`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/vector.py#L33) (translation) to represent a 3D rigid transformation. This class enables operations such as composing transformations, computing inverse transformations, and applying transformations to 3D points. It supports constructing transformations from 4x4 homogeneous matrices, providing a flexible interface for manipulating protein coordinates.

These geometric data structures are enhanced for JAX compatibility through the [`StructOfArray`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/struct_of_array.py#L191) decorator, found in [`/google-deepmind/alphafold/alphafold/model/geometry/struct_of_array.py`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/struct_of_array.py). This decorator transforms standard Python dataclasses into JAX-compatible PyTrees, enabling efficient use with JAX's automatic differentiation and parallel computation capabilities. This allows these geometric objects to behave like structured arrays, facilitating seamless integration with the larger AlphaFold computational graph.

The overall organization in the [`/google-deepmind/alphafold/alphafold/model/geometry`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry) directory centralizes these geometric utilities, simplifying their import and use across the codebase. For testing these geometric calculations, a set of utility functions is provided in [`/google-deepmind/alphafold/alphafold/model/geometry/test_utils.py`](https://github.com/google-deepmind/alphafold/alphafold/model/geometry/test_utils.py), allowing for precise validation of rotation matrices, vectors, and rigid transformations.
