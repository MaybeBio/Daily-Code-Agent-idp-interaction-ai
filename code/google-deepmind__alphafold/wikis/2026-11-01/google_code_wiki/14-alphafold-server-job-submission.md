## AlphaFold Server Job Submission
The AlphaFold server automates protein structure prediction tasks through a standardized JSON file format, as detailed in [`/google-deepmind/alphafold/server/README.md`](https://github.com/google-deepmind/alphafold/server/README.md). This enables engineers to submit multiple modeling jobs with specified parameters and molecular entities, facilitating scalable and reproducible predictions. Each job within the JSON file includes a unique [`name`](https://github.com/google-deepmind/alphafold/pyproject.toml#L20), a list of [`modelSeeds`](https://github.com/google-deepmind/alphafold/server/README.md#L31) for model initialization (an empty list is recommended for automatic seed assignment), and a [`sequences`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py#L33) array describing the molecules to be modeled. The JSON structure also requires a [`dialect`](https://github.com/google-deepmind/alphafold/server/README.md#L43) field set to [`"alphafoldserver"`](https://github.com/google-deepmind/alphafold/server/README.md#L58) and a [`version`](https://github.com/google-deepmind/alphafold/pyproject.toml#L63) field set to [`1`](https://github.com/google-deepmind/alphafold/LICENSE#L8), which supports features like [`maxTemplateDate`](https://github.com/google-deepmind/alphafold/server/README.md#L70) and [`useStructureTemplate`](https://github.com/google-deepmind/alphafold/server/README.md#L70).

The [`sequences`](https://github.com/google-deepmind/alphafold/alphafold/data/parsers.py#L33) array can define various molecular entities:
*   **Protein Chains**: These are specified with details such as the protein sequence, optional [`glycans`](https://github.com/google-deepmind/alphafold/server/README.md#L80) and [`modifications`](https://github.com/google-deepmind/alphafold/LICENSE#L27) (using CCD codes), [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334) for multiple copies, a boolean [`useStructureTemplate`](https://github.com/google-deepmind/alphafold/server/README.md#L70) (defaulting to [`true`](https://github.com/google-deepmind/alphafold/README.md#L376)), a [`maxTemplateDate`](https://github.com/google-deepmind/alphafold/server/README.md#L70) (ISO 8601 format) for template cutoff, and an optional [`unpairedMsa`](https://github.com/google-deepmind/alphafold/server/README.md#L111) in A3M format for Multiple Sequence Alignment. Custom structural [`templates`](https://github.com/google-deepmind/alphafold/README.md#L133) can also be provided as a list of dictionaries containing [`mmcif`](https://github.com/google-deepmind/alphafold/README.md#L160) content, along with [`queryIndices`](https://github.com/google-deepmind/alphafold/server/README.md#L122) and [`templateIndices`](https://github.com/google-deepmind/alphafold/server/README.md#L124) to map residues. For further details on how these entities are handled, see [Entity-Specific Modeling Parameters](#alphafold-server-job-submission-entity-specific-modeling-parameters).
*   **DNA Sequences**: These specify the single-stranded DNA sequence (A, T, G, C), [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334), and optional [`modifications`](https://github.com/google-deepmind/alphafold/LICENSE#L27) (using CCD codes). Double-stranded DNA modeling requires two [`dnaSequence`](https://github.com/google-deepmind/alphafold/server/README.md#L53) entries for the forward and reverse complement strands.
*   **RNA Sequences**: Similar to DNA, these define single-stranded RNA sequences (A, U, G, C), [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334), and optional [`modifications`](https://github.com/google-deepmind/alphafold/LICENSE#L27).
*   **Ligands and Ions**: These are specified by their respective [`CCD code`](https://github.com/google-deepmind/alphafold/server/README.md#L93) and [`count`](https://github.com/google-deepmind/alphafold/afdb/README.md#L334).

For a comprehensive understanding of the JSON structure, including all top-level fields and how sequences are defined, refer to [AlphaFold Server JSON Request Schema](#alphafold-server-job-submission-alphafold-server-json-request-schema). An initial template JSON file can be obtained by running a job via the AlphaFold Server GUI and extracting the [`<job_name>_job_request.json`](https://github.com/google-deepmind/alphafold/server/README.md#L20) file from the result zip.
