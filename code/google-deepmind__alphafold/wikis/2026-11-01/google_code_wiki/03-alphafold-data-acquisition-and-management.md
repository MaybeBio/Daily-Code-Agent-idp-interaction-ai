### AlphaFold Data Acquisition and Management
The AlphaFold system relies on a comprehensive collection of biological databases and model parameters for accurate protein structure prediction. These necessary data are acquired and organized through a set of automated scripts located in the [`/google-deepmind/alphafold/scripts`](https://github.com/google-deepmind/alphafold/scripts) directory. This modular approach ensures that various data types, each with its specific download and processing requirements, are handled systematically.

The central orchestration of the data download process is managed by the [`/google-deepmind/alphafold/scripts/download_all_data.sh`](https://github.com/google-deepmind/alphafold/scripts/download_all_data.sh) script. This script acts as a master controller, validating arguments and essential dependencies like [`aria2c`](https://github.com/google-deepmind/alphafold/README.md#L64) and [`rsync`](https://github.com/google-deepmind/alphafold/README.md#L67), then sequentially invoking specialized sub-scripts for each database. This modular design allows for efficient management and selective execution of data downloads, supporting both full and reduced database modes. For instance, depending on the chosen mode, it might download the entire BFD database via [`/google-deepmind/alphafold/scripts/download_bfd.sh`](https://github.com/google-deepmind/alphafold/scripts/download_bfd.sh) or a smaller version using [`/google-deepmind/alphafold/scripts/download_small_bfd.sh`](https://github.com/google-deepmind/alphafold/scripts/download_small_bfd.sh).

Beyond database acquisition, the system also requires AlphaFold's trained model parameters. These are downloaded and extracted by the [`/google-deepmind/alphafold/scripts/download_alphafold_params.sh`](https://github.com/google-deepmind/alphafold/scripts/download_alphafold_params.sh) script from a Google Cloud Storage URL, ensuring the prediction models are up-to-date.

Other scripts in this directory are dedicated to acquiring specific databases:
*   [`/google-deepmind/alphafold/scripts/download_mgnify.sh`](https://github.com/google-deepmind/alphafold/scripts/download_mgnify.sh) handles the MGnify database.
*   [`/google-deepmind/alphafold/scripts/download_pdb70.sh`](https://github.com/google-deepmind/alphafold/scripts/download_pdb70.sh) manages the PDB70 database.
*   [`/google-deepmind/alphafold/scripts/download_pdb_mmcif.sh`](https://github.com/google-deepmind/alphafold/scripts/download_pdb_mmcif.sh) downloads, decompresses, and flattens Protein Data Bank (PDB) mmCIF files, including an [`obsolete.dat`](https://github.com/google-deepmind/alphafold/README.md#L226) file for outdated entries.
*   [`/google-deepmind/alphafold/scripts/download_pdb_seqres.sh`](https://github.com/google-deepmind/alphafold/scripts/download_pdb_seqres.sh) retrieves the PDB Sequence Residue database and filters it to retain only protein sequences.
*   [`/google-deepmind/alphafold/scripts/download_uniref30.sh`](https://github.com/google-deepmind/alphafold/scripts/download_uniref30.sh) and [`/google-deepmind/alphafold/scripts/download_uniref90.sh`](https://github.com/google-deepmind/alphafold/scripts/download_uniref90.sh) download and extract the UniRef30 and UniRef90 databases, respectively.
*   [`/google-deepmind/alphafold/scripts/download_uniprot.sh`](https://github.com/google-deepmind/alphafold/scripts/download_uniprot.sh) downloads, unzips, and merges SwissProt and TrEMBL databases, which are essential for AlphaFold-Multimer.

These scripts consistently incorporate robust error handling, using [`set -e`](https://github.com/google-deepmind/alphafold/requirements.txt#L12) to ensure immediate exit upon command failure, thereby preventing incomplete or corrupted data installations. The use of [`aria2c`](https://github.com/google-deepmind/alphafold/README.md#L64) and [`rsync`](https://github.com/google-deepmind/alphafold/README.md#L67) further enhances download efficiency and reliability.
