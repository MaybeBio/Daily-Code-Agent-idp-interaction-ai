### AlphaFold Protein Structure Database Access and Querying
The AlphaFold Protein Structure Database, hosted on Google Cloud Public Datasets, contains a vast collection of protein structure predictions. Access methods include bulk downloads of the entire dataset or specific subsets. The database is organized into sharded [`tar`](https://github.com/google-deepmind/alphafold/README.md#L250) files (e.g., [`proteomes/proteome-tax_id-[TAX ID]-[SHARD ID]_v4.tar`](https://github.com/google-deepmind/alphafold/afdb/README.md#L88)) to optimize download performance by reducing latency associated with numerous small files, as detailed in [`/google-deepmind/alphafold/afdb/README.md`](https://github.com/google-deepmind/alphafold/afdb/README.md).

For bulk retrieval, users can employ [`gcloud storage cp`](https://github.com/google-deepmind/alphafold/afdb/README.md#L178) with recursive copy operations. Each protein entry within the database includes a [`model_v4.cif`](https://github.com/google-deepmind/alphafold/afdb/README.md#L70) file for atomic coordinates and metadata, a [`confidence_v4.json`](https://github.com/google-deepmind/alphafold/afdb/README.md#L74) file providing per-residue [`pLDDT`](https://github.com/google-deepmind/alphafold/README.md#L369) confidence metrics, and a [`predicted_aligned_error_v4.json`](https://github.com/google-deepmind/alphafold/afdb/README.md#L79) file containing [`PAE`](https://github.com/google-deepmind/alphafold/README.md#L258) confidence metrics. Auxiliary files such as [`accession_ids.csv`](https://github.com/google-deepmind/alphafold/afdb/README.md#L92) and [`sequences.fasta`](https://github.com/google-deepmind/alphafold/afdb/README.md#L100) are also available.

To facilitate custom subset creation and advanced data filtering, the database offers a metadata table ([`bigquery-public-data.deepmind_alphafold.metadata`](https://github.com/google-deepmind/alphafold/afdb/README.md#L271)) accessible via Google Cloud's BigQuery. This allows users to query fields such as [`organismScientificName`](https://github.com/google-deepmind/alphafold/afdb/README.md#L312), [`fractionPlddtVeryHigh`](https://github.com/google-deepmind/alphafold/afdb/README.md#L302), [`taxId`](https://github.com/google-deepmind/alphafold/afdb/README.md#L276), [`uniprotAccession`](https://github.com/google-deepmind/alphafold/afdb/README.md#L319), and [`uniprotSequence`](https://github.com/google-deepmind/alphafold/afdb/README.md#L275) to generate manifest files for targeted downloads, as described in [`/google-deepmind/alphafold/afdb/README.md`](https://github.com/google-deepmind/alphafold/afdb/README.md). This capability enables researchers to retrieve only the data relevant to their specific interests, avoiding the need to download the entire dataset.
