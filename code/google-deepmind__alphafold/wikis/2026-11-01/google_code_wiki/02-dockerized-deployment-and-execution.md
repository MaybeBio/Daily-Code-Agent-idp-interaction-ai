### Dockerized Deployment and Execution
AlphaFold's deployment and execution within a containerized environment is managed through Docker. This approach ensures consistent and reproducible protein structure predictions. The Docker setup involves a [`Dockerfile`](https://github.com/google-deepmind/alphafold/README.md#L106) for environment configuration, dependency installation, and GPU support, coupled with a Python script that orchestrates container execution, including data mounts and argument passing.

The Docker image is defined by the [`/google-deepmind/alphafold/docker/Dockerfile`](https://github.com/google-deepmind/alphafold/docker/Dockerfile). This file details the steps for building a robust Docker image, starting from an [`nvidia/cuda`](https://github.com/google-deepmind/alphafold/README.md#L88) base to enable GPU acceleration. It handles the installation of system dependencies, compiles bioinformatics tools like [`hh-suite`](https://github.com/google-deepmind/alphafold/README.md#L732) from source, and sets up a Miniconda environment for Python. Key steps include copying the AlphaFold application code, installing Python dependencies (including specific [`jax`](https://github.com/google-deepmind/alphafold/README.md#L735) and [`jaxlib`](https://github.com/google-deepmind/alphafold/docker/Dockerfile#L72) versions with CUDA support), and configuring necessary library paths. A custom entrypoint script, [`/app/run_alphafold.sh`](https://github.com/google-deepmind/alphafold/docker/Dockerfile#L89), is created to address GPU visibility issues on Debian-based images before launching the main AlphaFold Python script.

The execution of AlphaFold within this Docker container is managed by [`/google-deepmind/alphafold/docker/run_docker.py`](https://github.com/google-deepmind/alphafold/docker/run_docker.py). This Python script parses command-line flags to control various AlphaFold parameters, such as GPU usage, input FASTA paths, output directories, and database presets. It programmatically constructs absolute paths for necessary database files and input data. The script then generates Docker mount objects to bind host directories and files into the container, making data accessible to AlphaFold. It initializes a Docker client, configures GPU access, and executes the AlphaFold container, passing configured arguments and setting environment variables for GPU memory optimization. The script also includes signal handling to gracefully terminate the container upon interruption and streams container output for monitoring. The Python dependencies for this orchestration script are defined in [`/google-deepmind/alphafold/docker/requirements.txt`](https://github.com/google-deepmind/alphafold/docker/requirements.txt), which pins [`absl-py`](https://github.com/google-deepmind/alphafold/pyproject.toml#L40) and [`docker`](https://github.com/google-deepmind/alphafold/README.md#L47) to specific versions for consistent operation.
