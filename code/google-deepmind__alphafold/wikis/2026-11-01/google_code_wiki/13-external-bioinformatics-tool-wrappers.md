### External Bioinformatics Tool Wrappers
The AlphaFold pipeline integrates with various third-party bioinformatics tools, such as [`HHblits`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L79), [`HHsearch`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L84), [`Jackhmmer`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L31), [`hmmbuild`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmbuild.py#L27), [`hmmsearch`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmsearch.py#L29), and [`Kalign`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L36), to generate the essential input features for protein structure prediction. Python wrappers are provided in [`/google-deepmind/alphafold/alphafold/data/tools`](https://github.com/google-deepmind/alphafold/alphafold/data/tools) to manage the execution of these external tools, handle temporary files, parse their output, and streamline their integration into the overall AlphaFold workflow.

These wrappers abstract the complexities of subprocess execution and command-line argument construction. For instance, the [`HHBlits`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhblits.py#L32) class in [`/google-deepmind/alphafold/alphafold/data/tools/hhblits.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhblits.py) manages parameters like CPU count, number of iterations, and E-value thresholds, executing the [`HHblits`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L79) binary to perform protein sequence database searches and generate multiple sequence alignments (MSAs). Similarly, the [`HHSearch`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhsearch.py#L29) class in [`/google-deepmind/alphafold/alphafold/data/tools/hhsearch.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hhsearch.py) provides an interface for [`HHsearch`](https://github.com/google-deepmind/alphafold/run_alphafold.py#L84) queries, parsing HHR output into structured template hit objects.

For profile HMM construction and searching, the [`Hmmbuild`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmbuild.py#L27) class in [`/google-deepmind/alphafold/alphafold/data/tools/hmmbuild.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmbuild.py) builds HMM profiles from MSAs (either Stockholm or A3M format), while the [`Hmmsearch`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmsearch.py#L29) class in [`/google-deepmind/alphafold/alphafold/data/tools/hmmsearch.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/hmmsearch.py) then queries sequence databases with these profiles. The [`Jackhmmer`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L31) class in [`/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py) wraps the [`jackhmmer`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L31) binary for homology searches, supporting both local and streamed database queries. This streaming capability, enabled by [`num_streamed_chunks`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L49) and [`streaming_callback`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/jackhmmer.py#L50), allows efficient processing of very large databases by concurrently downloading and processing data chunks. Finally, the [`Kalign`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L36) class in [`/google-deepmind/alphafold/alphafold/data/tools/kalign.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py) handles multiple sequence alignments, preparing input sequences and executing the [`Kalign`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L36) binary.

Each wrapper employs [`subprocess.Popen`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L90) for command execution and utilizes [`tmpdir_manager`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/utils.py#L25) from [`/google-deepmind/alphafold/alphafold/data/tools/utils.py`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/utils.py) to ensure robust temporary file management and cleanup. Error handling is detailed, typically raising [`RuntimeError`](https://github.com/google-deepmind/alphafold/alphafold/model/prng.py#L37) with [`stdout`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L91) and [`stderr`](https://github.com/google-deepmind/alphafold/alphafold/data/tools/kalign.py#L91) to provide diagnostics for tool failures. These wrappers are crucial for automating the feature generation step, which is a prerequisite for the [AlphaFold Inference Pipeline](#alphafold-inference-pipeline).
