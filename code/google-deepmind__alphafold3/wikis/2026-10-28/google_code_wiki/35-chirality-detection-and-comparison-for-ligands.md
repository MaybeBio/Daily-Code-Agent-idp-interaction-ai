### Chirality Detection and Comparison for Ligands
The system includes functionalities for detecting and comparing the chirality of ligand molecules within a structure. This process is handled by the functions within [`/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py), which use [`rd_chem`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L40) for molecular operations, focusing on chiral centers typically involving carbon and sulfur atoms.

The [`compare_chirality`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L149) function serves as the main entry point for this process. It takes a [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) object representing the ligand and, optionally, a mapping of reference molecules. If a reference molecule is not provided for a specific ligand, the system attempts to retrieve molecular information from the Chemical Components Dictionary (CCD) based on the ligand's residue name using [`_maybe_mol_from_ccd`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L127). The ligand's structure is then converted into an [`rd_chem.Mol`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/rdkit_utils.py#L60) object via [`_mol_from_ligand_struc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L80).

Once [`rd_chem.Mol`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/rdkit_utils.py#L60) objects are available for both the test ligand and its reference, the [`_chiral_match`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L58) function compares their chirality. This comparison involves identifying chiral centers in both molecules using [`_find_chiral_centres`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L33) and verifying that all chiral centers in the test molecule match those in the reference. The system accommodates scenarios where the ligand molecule might be a subset of the reference molecule. The output is a dictionary indicating whether the chirality of each ligand chain matches its reference.
