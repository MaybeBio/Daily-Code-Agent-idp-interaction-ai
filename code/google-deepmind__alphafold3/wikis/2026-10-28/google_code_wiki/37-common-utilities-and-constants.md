## Common Utilities and Constants
The AlphaFold 3 codebase includes a foundational set of utilities and constants that underpin its molecular modeling capabilities. This shared infrastructure ensures consistent data handling, configuration management, and access to critical molecular definitions across various modules.

A robust configuration management system, defined in [`/google-deepmind/alphafold3/src/alphafold3/common/base_config.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/base_config.py), enables the creation of flexible and nested configuration objects. This system automatically converts configuration dictionaries into typed data structures and allows for specifying default factories, which simplifies the process of defining and loading model parameters.

For managing biological input data, the codebase defines specialized structures for various entities like protein, RNA, DNA chains, and ligands in [`/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py). These structures support deserialization from and serialization to different JSON dialects (AlphaFold 3 and AlphaFoldServer) and mmCIF formats, facilitating interoperability with external data sources. The system includes validation mechanisms to ensure data integrity, handles sequence modifications, and processes Multiple Sequence Alignments (MSAs) and structural templates.

Secure data loading is addressed by the [`safe_pickle`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py#L28) module in [`/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py). This module provides a restricted wrapper around Python's [`pickle`](https://github.com/google-deepmind/alphafold3/run_alphafold_test.py#L29) functionality, allowing only an explicit allowlist of built-in, innocuous types to be unpickled. This prevents arbitrary code execution from potentially malicious or corrupted pickled data files, crucial for maintaining the integrity of constant data distributed with the repository.

Access to external data files and resources is managed through the [`resources`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L49) module in [`/google-deepmind/alphafold3/src/alphafold3/common/resources.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/resources.py). This module provides utilities to locate files relative to the package root, open them in various modes, and traverse resource directories, ensuring consistent access to necessary external assets.

The definition of molecular properties and constants is centralized in the [`/google-deepmind/alphafold3/src/alphafold3/constants`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants) directory. This includes a comprehensive mapping of atom types for proteins and nucleic acids, along with structured representations such as [`ATOM37`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/atom_types.py#L143) and [`ATOM14`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/atom_types.py#L154) in [`/google-deepmind/alphafold3/src/alphafold3/constants/atom_types.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/atom_types.py). These definitions are critical for consistent atom identification and data storage in fixed-size arrays.

Chemical component properties, derived from the Chemical Components Dictionary (CCD), are managed by [`/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py). This includes the [`Ccd`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py#L46) class, which loads CCD data from a pickle file and provides dictionary-like access to component information, with support for user-defined overrides. Additionally, [`/google-deepmind/alphafold3/src/alphafold3/constants/chemical_component_sets.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_component_sets.py) defines predefined sets of chemical components, categorizing ligands and crystallization aids for specialized handling. Tools in [`/google-deepmind/alphafold3/src/alphafold3/constants/converters`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/converters) are responsible for converting raw CCD CIF files into these efficient pickled formats.

Standardization of residue names and chain types is handled in [`/google-deepmind/alphafold3/src/alphafold3/constants/residue_names.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/residue_names.py) and [`/google-deepmind/alphafold3/src/alphafold3/constants/mmcif_names.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/mmcif_names.py). These files provide mappings between three-letter and one-letter residue codes, categorize residue types (e.g., standard, unknown, gap), and define utility functions to infer and standardize polymer types from mmCIF data.

A static periodic table of elements, including atomic numbers, symbols, and weights, is defined in [`/google-deepmind/alphafold3/src/alphafold3/constants/periodic_table.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/periodic_table.py). This provides a consistent and efficient lookup for elemental properties, which is foundational for various molecular operations.

Finally, specific constants related to amino acid side chain torsion angles, such as [`CHI_ANGLES_ATOMS`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/side_chains.py#L28) and [`CHI_ANGLES_MASK`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/side_chains.py#L99), are defined in [`/google-deepmind/alphafold3/src/alphafold3/constants/side_chains.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/side_chains.py). These constants are essential for calculating and masking chi angles in protein structures, directly supporting the model's ability to predict detailed side chain conformations.
