### 3D Vector (`Vec3Array`) Operations
The [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py), provides a JAX-compatible representation for 3D vectors. This class utilizes a struct-of-arrays design, where the x, y, and z components of a collection of vectors are stored in separate JAX arrays. This design choice is aimed at optimizing performance and numerical precision, particularly on accelerator hardware like TPUs, by facilitating vectorized operations. The [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class integrates with JAX's pytree mechanisms through the [`StructOfArray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py#L199) decorator, allowing seamless use with JAX transformations such as [`jax.vmap`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/featurization.py#L47) and [`jax.jit`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L488). For more information on this design, see [Struct-of-Arrays Design for JAX Compatibility](#geometric-primitives-and-operations-struct-of-arrays-design-for-jax-compatibility).

The [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class supports fundamental vector arithmetic, including addition, subtraction, multiplication, and division, all of which are overloaded operators for intuitive use. It also provides methods for geometric calculations:
*   [`cross`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L87) and [`dot`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L94): Compute the cross and dot products of vectors.
*   [`norm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L98) and [`norm2`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L106): Calculate the L2 norm (magnitude) and squared L2 norm, respectively. [`norm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L98) includes numerical stability features to prevent issues with very small values.
*   [`normalized`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L109): Returns a unit vector.

Conversion utilities such as [`to_array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L122) and [`from_array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L126) allow for easy transformation between the [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) object and standard JAX array representations.

Beyond the [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class itself, the module includes related functions that operate on these vector types:
*   [`square_euclidean_distance`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L142) and [`euclidean_distance`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L180): Compute the squared and standard Euclidean distances between two [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) instances.
*   [`dihedral_angle`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L200): Calculates the torsion (dihedral) angle between four 3D points represented as vectors, a common operation in molecular geometry.
*   [`random_gaussian_vector`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L229): Generates random vectors with components drawn from a standard normal distribution.

These functionalities are aggregated and re-exported through the top-level [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/__init__.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/__init__.py) module to simplify access.
