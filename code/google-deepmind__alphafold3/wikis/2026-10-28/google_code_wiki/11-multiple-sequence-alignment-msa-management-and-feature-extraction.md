### Multiple Sequence Alignment (MSA) Management and Feature Extraction
Multiple Sequence Alignment (MSA) management in AlphaFold 3 involves the structured representation, manipulation, and featurization of MSA data, crucial for providing the model with evolutionary information. The central component for this is the [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/data/msa.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py). This class acts as a container for MSA sequences and their associated descriptions, ensuring consistency by verifying that all sequences originate from the same query and polymer type.

The [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) class supports initialization from various sources. It can be constructed directly from A3M-formatted strings via methods like [`from_a3m`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L208) and [`from_multiple_a3ms`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L165), or by merging existing [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) objects using [`from_multiple_msas`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L122). For cases where no external MSA is available, an empty [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) containing only the query sequence can be created with [`from_empty`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L238). A key aspect of [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) management is deduplication, which occurs during initialization and through dedicated methods. This process specifically handles lowercase characters, treating them as insertions that should be ignored when identifying unique sequences.

The conversion of raw MSA data into numerical features suitable for the model is handled by the [`featurize`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L263) method of the [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) class. This method leverages helper functions in [`/google-deepmind/alphafold3/src/alphafold3/data/msa_features.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_features.py) to extract features such as the numerical representation of sequences ([`msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61)), a matrix quantifying deletions ([`deletion_matrix`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L417)), and species identifiers. The [`/google-deepmind/alphafold3/src/alphafold3/data/msa_features.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_features.py) module includes specific character mappings for protein, RNA, and DNA residues, and uses regular expressions to parse UniProtKB-formatted descriptions to extract species IDs. These species IDs are then encapsulated in an [`Identifiers`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py#L55) dataclass, as defined in [`/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py).

For computationally intensive tasks like MSA profile computation, AlphaFold 3 utilizes high-performance C++ implementations. The [`ComputeMsaProfile`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc#L31) function, located in [`/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc), calculates a residue frequency profile from an integer-encoded MSA. This profile indicates the frequency of each residue type at every position in the MSA, normalized by the MSA depth. This C++ functionality is exposed to Python through [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148) via the [`RegisterModuleMsaProfile`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.h#L27) function, allowing Python components to benefit from the speed of C++ for this specific task. The configuration for MSA tools, including external search tools like Jackhmmer and Nhmmer, is managed through dataclasses defined in [`/google-deepmind/alphafold3/src/alphafold3/data/msa_config.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_config.py), allowing for flexible parameter settings for database paths, CPU usage, and various statistical thresholds. External tools themselves are wrapped in Python classes as described in [HMMER Suite Wrappers for MSA and Template Search](#input-feature-generation-hmmer-suite-wrappers-for-msa-and-template-search).
