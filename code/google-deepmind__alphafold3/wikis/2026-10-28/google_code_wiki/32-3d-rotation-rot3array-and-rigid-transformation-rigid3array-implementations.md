### 3D Rotation (`Rot3Array`) and Rigid Transformation (`Rigid3Array`) Implementations
The AlphaFold 3 codebase extensively uses [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) for representing 3D rotation matrices and [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) for rigid transformations, both designed for efficient batch operations within a JAX environment. These classes, found primarily in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py) and [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py), utilize a struct-of-arrays design, where components (e.g., [`xx`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L121), [`xy`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L122) for rotation matrices, or [`x`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L51), [`y`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L52), [`z`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L53) for vectors) are stored as separate arrays rather than interleaved within a single array. This approach optimizes performance on accelerators by aligning with how JAX processes array data. For more information on the struct-of-arrays design, refer to [Struct-of-Arrays Design for JAX Compatibility](#geometric-primitives-and-operations-struct-of-arrays-design-for-jax-compatibility).

The [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) class encapsulates a 3x3 rotation matrix. It supports fundamental matrix operations such as computing its [`inverse`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L133) (which is simply its transpose for rotation matrices) and applying the rotation to a 3D point ([`apply_to_point`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L141)). Multiple [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) instances can be composed using matrix multiplication ([`__matmul__`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L153)), allowing for sequential transformations. Various methods are provided for constructing rotation matrices, including [`from_two_vectors`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L168) to define a rotation based on two directional vectors, [`from_quaternion`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L209) for conversion from quaternion representation, and [`from_svd`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L237) which uses Singular Value Decomposition for robust construction from arbitrary 3x3 matrices, even when they are not perfectly orthonormal.

Building upon [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118), the [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) class represents a rigid body transformation, which combines a 3D rotation ([`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118)) with a 3D translation ([`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38)). Like [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118), it supports composition via matrix multiplication and can compute its [`inverse`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L133). It also provides methods to [`apply_to_point`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L141) or apply the inverse transformation to a point. A key functionality is [`from_point_alignment`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L181), which determines the optimal rigid transformation to align one set of points to another. This is achieved by computing a weighted covariance matrix between the two sets of points and then deriving the rotation and translation components. The [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class and its operations are detailed in [3D Vector (`Vec3Array`) Operations](#geometric-primitives-and-operations-3d-vector-vec3array-operations).
