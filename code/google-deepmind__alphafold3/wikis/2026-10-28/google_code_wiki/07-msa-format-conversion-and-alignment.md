### MSA Format Conversion and Alignment
The system provides C++ utilities for converting Multiple Sequence Alignment (MSA) data between formats, specifically from A3M to Stockholm format, and for aligning sequences to a gapless query. These functionalities are exposed to Python through [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148) bindings, allowing high-performance MSA processing within a Python environment.

The [`ConvertA3MToStockholm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc#L36) function, found in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc), transforms A3M-formatted sequences into Stockholm format. This conversion handles insertions (lowercase characters in A3M) by promoting them to uppercase and appropriately padding other sequences with dashes ([`-`](https://github.com/google-deepmind/alphafold3/README.md#L75)) to maintain alignment. The function ensures consistency across sequences and raises an [`std::invalid_argument`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc#L81) error if it encounters A3M input with inconsistent row lengths.

The [`AlignSequenceToGaplessQuery`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc#L92) function, also within [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc), aligns a given [`sequence`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L251) to a [`query_sequence`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L582) that is assumed to be gapless. This process identifies residues in the input [`sequence`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L251) that represent insertions relative to the query by converting them to lowercase. This is useful for tasks such as converting Stockholm MSA back to A3M format, where insertions relative to a query sequence need to be explicitly marked. A [`py::value_error`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/cif_dict_pybind.cc#L389) is raised if the input sequences do not have matching lengths.

These C++ functions are accessible in Python via bindings registered by [`RegisterModuleMsaConversion`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.h#L27) in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion_pybind.cc). This allows Python code to call [`convert_a3m_to_stockholm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/parsers.py#L73) and [`align_sequence_to_gapless_query`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/msa_conversion.pyi#L29), leveraging the performance of C++ for these critical data manipulation steps while benefiting from Python's flexibility. The bindings release the Python Global Interpreter Lock (GIL) during C++ execution to enable concurrency and improve overall application performance. For more details on the C++/Python binding mechanisms, see [C++/Python Bindings and Performance](#data-parsing-and-preprocessing-cpython-bindings-and-performance).
