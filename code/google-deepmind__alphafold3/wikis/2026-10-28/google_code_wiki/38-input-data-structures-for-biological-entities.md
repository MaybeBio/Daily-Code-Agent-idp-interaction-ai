### Input Data Structures for Biological Entities
Biological input data for AlphaFold 3 is managed through a set of structured data classes defined in [`/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py). These classes represent various molecular entities and their associated information, ultimately encapsulated within a central [`Input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L976) object.

Specific chain types are defined for proteins, RNA, and DNA, along with a distinct type for ligands:
*   [`ProteinChain`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L183): Represents a protein, including its sequence, post-translational modifications, and associated Multiple Sequence Alignments (MSAs) and structural templates.
*   [`RnaChain`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L481): Represents an RNA molecule, incorporating its sequence, modifications, and MSAs.
*   [`DnaChain`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L690): Represents a DNA molecule, similar to [`RnaChain`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L481) but for DNA-specific modifications.
*   [`Ligand`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L834): Represents a ligand, identified either by Chemical Component Dictionary (CCD) IDs or by a SMILES string.

Structural template information, used as a reference for predictions, is handled by the [`Template`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L98) class, which stores an mmCIF string and a mapping of query residues to template residues.

The [`Input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L976) dataclass serves as the primary container for a complete biological system. It aggregates various [`chains`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L114) (which can be any combination of protein, RNA, DNA, or ligand), assigns a [`name`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L427), and includes [`rng_seeds`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1001) for model execution randomness. It also stores [`bonded_atom_pairs`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1002) to define inter-chain chemical bonds and can incorporate [`user_ccd`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1003) for custom chemical components.

The system supports both serialization and deserialization of these input structures. [`Input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L976) objects can be created from JSON (supporting both AlphaFold 3 and AlphaFoldServer dialects) or mmCIF formats using methods like [`from_json`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1152) and [`from_mmcif`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/parsing.py#L408). Conversely, an [`Input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L976) object can be converted back into JSON via [`to_json`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1485) or transformed into a [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) object for internal model processing via [`to_structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L1414). The conversion to [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) involves mapping chain sequences and modifications to CCD codes, which are standardized representations of chemical components.

Utility functions are provided for reading compressed external data files (like MSAs or mmCIFs) referenced within JSON inputs, ensuring paths are correctly resolved relative to the input file. The system prioritizes data integrity through extensive validation during object initialization and parsing, checking for consistent IDs, valid sequences, and correct formatting of bond information. Additionally, the design uses immutable data structures, where modifications typically return new instances, enhancing predictability. Default values for missing fields (such as MSAs or templates) can be populated via [`fill_missing_fields`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/folding_input.py#L468). For more information on the underlying configuration system, refer to [Common Utilities and Constants](#common-utilities-and-constants).
