### Chemical Component Data Generation and Processing
The Chemical Components Dictionary (CCD) defines the properties of every residue and ligand referred to in the Protein Data Bank (PDB). AlphaFold 3 processes this raw CCD data to convert it into a more usable format for its models, and to categorize specific chemical components into predefined sets. This process involves two main stages: converting raw CCD CIF files into pickled Python objects, and subsequently categorizing these components.

The first stage is handled by the script found in [`/google-deepmind/alphafold3/src/alphafold3/constants/converters/ccd_pickle_gen.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/converters/ccd_pickle_gen.py). This script reads a CCD file, which is typically in CIF format and potentially gzipped, and parses its contents using [`cif_dict.parse_multi_data_cif`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/mmcif.py#L124) from the C++ parsing utilities (see [CIF Data Structures and Serialization](#data-parsing-and-preprocessing-cif-data-structures-and-serialization)). The parsed data is then serialized into a Python pickle file. This conversion optimizes access and storage of the extensive CCD information.

Following the initial conversion, the script located in [`/google-deepmind/alphafold3/src/alphafold3/constants/converters/chemical_component_sets_gen.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/converters/chemical_component_sets_gen.py) further processes the pickled CCD. Its primary function is to identify and categorize chemical components as linking glycans, other glycans, or ions. This categorization is crucial for downstream model operations that might treat these molecular types differently. The script loads the pre-generated CCD pickle file using [`safe_pickle.load`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py#L43), which ensures secure data handling by allowing only explicitly trusted types during deserialization (see [Secure Data Loading with Restricted Pickle](#common-utilities-and-constants-secure-data-loading-with-restricted-pickle)). It then iterates through each chemical component, applying pattern matching on their type and name fields to classify them. The classified components are stored as immutable [`frozenset`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L54) objects within a dictionary, which is then saved to a new pickle file. These processed sets are later utilized for various model inputs and chemical component definitions (see [Atom Type and Chemical Component Definitions](#common-utilities-and-constants-atom-type-and-chemical-component-definitions)).
