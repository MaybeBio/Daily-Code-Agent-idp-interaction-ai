## Core Model Architecture and Pipeline
The AlphaFold 3 model's architecture integrates several components, from processing initial input features to predicting molecular structures and scoring their confidence. The overall model is implemented in the [`Model`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L225) class within [`/google-deepmind/alphafold3/src/alphafold3/model/model.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py). This class orchestrates the conversion of input data into a feature batch, refines embeddings using an Evoformer, samples atom positions through a diffusion head, and calculates confidence scores and distogram predictions.

A crucial aspect of the pipeline involves converting raw macromolecular entities, typically from mmCIF files, into model-ready feature objects. This is managed by the [`WholePdbPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L86) class located in [`/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py). This pipeline includes several steps such as cleaning the input structure by removing non-standard atoms, water, and hydrogens. It also identifies and processes inter-chain bonds between polymers and ligands or between ligands themselves, which is essential for understanding molecular interactions. The pipeline then tokenizes atoms into units suitable for the model and generates a diverse set of features, including Multiple Sequence Alignment (MSA), template information, and reference structures. Data padding is applied to ensure consistent input dimensions for batch processing. For more details on the transformation of raw biological data into model-ready inputs, refer to [Macromolecular Data Processing Pipeline](#core-model-architecture-and-pipeline-macromolecular-data-processing-pipeline).

The neural network's backbone is defined within the [`/google-deepmind/alphafold3/src/alphafold3/model/network`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network) directory. This includes architectures such as the Evoformer and Pairformer, which are responsible for refining sequence and pair embeddings. These modules incorporate information like relative position encodings, bond details, and template features. Atom-level cross-attention mechanisms are also employed, which are critical for integrating atom-specific information. The model leverages a diffusion denoising process, implemented in the [`DiffusionHead`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L110) within [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py), to iteratively sample and refine atom positions, ultimately leading to structure generation. These core network components are further elaborated in [Core Network Architectures](#core-model-architecture-and-pipeline-core-network-architectures).

Beyond structure prediction, AlphaFold 3 also provides mechanisms for assessing the quality and reliability of its predictions. Confidence scoring modules, found in [`/google-deepmind/alphafold3/src/alphafold3/model/network/confidence_head.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/confidence_head.py) and [`/google-deepmind/alphafold3/src/alphafold3/model/confidences.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/confidences.py), predict metrics such as predicted distance errors (PDE), predicted aligned errors (PAE), and predicted lDDT. These modules are crucial for evaluating the accuracy of the structural models. Utilities for structural analysis, like clash detection and solvent accessibility calculations, further aid in post-processing and validating model outputs. See [Confidence Scoring and Structural Analysis Utilities](#core-model-architecture-and-pipeline-confidence-scoring-and-structural-analysis-utilities) for a deeper dive into these features.

The model also utilizes various Haiku modules, defined in [`/google-deepmind/alphafold3/src/alphafold3/model/components/haiku_modules.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/components/haiku_modules.py), such as custom [`LayerNorm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/components/haiku_modules.py#L50) and [`Linear`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/components/haiku_modules.py#L197) layers, designed for numerical stability and mixed-precision training. Utilities for sharded mapping, located in [`/google-deepmind/alphafold3/src/alphafold3/model/components/mapping.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/components/mapping.py), manage memory and throughput by processing data in smaller chunks. These components are vital for optimizing model performance and resource utilization. Additional details on these can be found in [Haiku Modules and Optimization Utilities](#core-model-architecture-and-pipeline-haiku-modules-and-optimization-utilities).
The output of the model, including structural predictions and confidence metrics, is then processed and saved using functionalities in [`/google-deepmind/alphafold3/src/alphafold3/model/post_processing.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/post_processing.py). This step also involves adding ModelCIF-compliant metadata to the generated mmCIF files to ensure data provenance and quality reporting, as detailed in [`/google-deepmind/alphafold3/src/alphafold3/model/mmcif_metadata.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/mmcif_metadata.py). For efficient serialization of complex confidence data, C++ implementations are exposed to Python using Pybind11, as seen in [`/google-deepmind/alphafold3/src/alphafold3/model/json_serialize_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/json_serialize_pybind.cc).
