### Template Retrieval, Filtering, and Realignment
Structural templates play a crucial role in the AlphaFold 3 prediction pipeline by providing existing structural information that can guide the model. The system manages the retrieval, filtering, and featurization of these templates to ensure high-quality and relevant structural data is used as input.

Template retrieval often begins with sequence searches against structural databases. The system leverages HMMER suite tools such as [`hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) to identify potential structural homologs. For instance, [`hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) can be executed by [`run_hmmsearch_with_a3m`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L968) in [`/google-deepmind/alphafold3/src/alphafold3/data/templates.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py), using an input Multiple Sequence Alignment (MSA) to query a database and produce a list of template candidates. These candidates, or "hits," are encapsulated in [`Hit`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L167) objects defined in [`/google-deepmind/alphafold3/src/alphafold3/data/templates.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py). Each [`Hit`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L167) stores critical metadata, including the PDB ID, chain ID, sequences, and release date, as well as alignment information.

Once potential templates are identified, they undergo a rigorous filtering process. The [`filter`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L610) method of the [`Templates`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L719) class, located in [`/google-deepmind/alphafold3/src/alphafold3/data/templates.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py), applies various criteria defined in [`msa_config.TemplateFilterConfig`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L459) in [`/google-deepmind/alphafold3/src/alphafold3/data/msa_config.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_config.py). These filters include checking for maximum subsequence ratios, minimum alignment ratios, minimum hit lengths, and ensuring that templates are not too recent based on a [`release_date_cutoff`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py#L598). Duplicate sequences are also removed to prevent redundancy. This step ensures that only the most relevant and reliable templates are passed on for featurization.

A significant challenge in using structural templates is reconciling discrepancies between sequences obtained from sequence databases (like those used by [`hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31), which often rely on PDB SEQRES records) and the actual sequences present in the mmCIF structural files. The [`realign_hit_to_structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py#L29) function in [`/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py) addresses this by adjusting the mapping from the query sequence to the precise structural sequence. It iteratively attempts to realign the template hit sequence with the mmCIF structure sequence, accounting for potential insertions or deletions. This process helps to generate an accurate mapping, ensuring that the model's input features correctly reflect the true structural context.

Finally, the filtered and realigned template hits are featurized. The [`featurize`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L263) method in [`/google-deepmind/alphafold3/src/alphafold3/data/templates.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py) extracts structural and sequence features for both polymer chains and ligands from the selected [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) objects (see [Molecular Structure Management](#molecular-structure-management)). These features include atomic positions, masks, sequence identity, and amino acid types. These extracted features are then packaged into a structured format suitable for consumption by the AlphaFold 3 model.
