### Featurization Pipeline and Data Orchestration
The featurization pipeline in AlphaFold 3 processes raw biological data into a structured format suitable for model inference. This process begins with [`validate_fold_input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py#L33) in [`/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py), which ensures the integrity of input data ([`folding_input.Input`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L566)) by checking for required fields such as unpaired Multiple Sequence Alignments (MSAs), paired MSAs, and templates for protein chains, or unpaired MSAs for RNA chains. The primary function for orchestrating this conversion is [`featurise_input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py#L47), also in [`/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py). This function converts the validated [`folding_input.Input`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L566) into [`features.BatchDict`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L480) objects. It supports the generation of multiple featurized batches by processing data with different random seeds, which can be valuable for ensemble predictions or robust analysis.

The [`featurise_input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py#L47) function leverages the [`DataPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L304) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py), to manage the computationally intensive tasks of MSA and template generation. The [`DataPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L304) orchestrates these processes in parallel using thread pools, making the data preparation efficient. For proteins, it generates MSAs using tools like Jackhmmer and performs template searches with Hmmsearch against various databases. For RNA chains, it generates MSAs using Nhmmer against RNA-specific databases. The pipeline intelligently skips searches if the required data is already present in the input. After these tools run, the [`DataPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L304) aggregates the results (MSAs and templates) into a structured format ready for the AlphaFold model. The [`DataPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L304) uses configurations defined in [`msa_config.RunConfig`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L333) and [`msa_config.TemplatesConfig`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L44) to control parameters for each specific MSA and template search tool, including database details, E-values, and CPU usage. This modular and configurable design allows for flexible setup and execution of the featurization process.
