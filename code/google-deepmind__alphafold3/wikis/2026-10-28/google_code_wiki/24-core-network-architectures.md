### Core Network Architectures
The core network architectures in AlphaFold 3 are primarily responsible for refining molecular representations and generating new structures. This involves three main components: the Evoformer/Pairformer for refining sequence and pairwise embeddings, atom-level cross-attention mechanisms for detailed atomic interactions, and a generative diffusion denoising process for structure prediction. These components are implemented using Haiku modules and JAX for efficient computation.

The [`Evoformer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L39) module, defined in [`/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py), processes diverse input features to generate and refine 'single' (per-residue) and 'pair' (pairwise interaction) embeddings. It integrates relative position information, chemical bond data, structural template features, and Multiple Sequence Alignment (MSA) derived features. The [`_relative_encoding`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L86) function in [`/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py) generates features based on the relative positions of tokens and residues, including chain and symmetry identifiers. Bond information is incorporated by [`_embed_bonds`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L129) in [`/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py), which creates a contact matrix from polymer-ligand and ligand-ligand bond data. Template features are embedded by [`_embed_template_pair`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L180) in [`/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py), leveraging the [`TemplateEmbedding`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/template_modules.py#L118) module from [`/google-deepmind/alphafold3/src/alphafold3/model/network/template_modules.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/template_modules.py) to process structural templates. MSA features are processed through [`_embed_process_msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L209) in [`/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py), which uses modules such as [`EvoformerIteration`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L542) and [`PairFormerIteration`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L422) from [`/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py) for iterative refinement. The [`PairFormerIteration`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L422) block, central to both the Evoformer and the final refinement stages, applies operations like [`TriangleMultiplication`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L254) and [`GridSelfAttention`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L140) to iteratively update both single and pair representations.

Atom-level cross-attention mechanisms, defined in [`/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py), are used to encode and decode atomic information. The [`atom_cross_att_encoder`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py#L126) processes initial atom features and conditions them with [`trunk_single_cond`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L169) and [`trunk_pair_cond`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L170), which represent higher-level single and pair conditioning information. It utilizes [`atom_layout.convert`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L98) to efficiently manage data transformations between different atom representations. This encoder aggregates atom-level information into token features. Conversely, the [`atom_cross_att_decoder`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py#L370) takes token-level activations and decodes them back into atom position updates, using information from the encoder and refined conditioning. Both the encoder and decoder rely on [`diffusion_transformer.CrossAttTransformer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py#L37) from [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py) for their core attention mechanisms, enabling interactions between atom-level queries and key features.

The generative diffusion denoising process, managed by the [`DiffusionHead`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L110) module in [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py), is responsible for predicting atomic coordinates. This module takes noisy atom positions and iteratively denoises them to generate a stable structure. The [`_conditioning`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L143) method within [`DiffusionHead`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L110) prepares [`single_cond`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L178) and [`pair_cond`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/atom_cross_attention.py#L116) embeddings by incorporating various features and noise level embeddings from [`noise_level_embeddings.noise_embeddings`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L189) in [`/google-deepmind/alphafold3/src/alphafold3/model/network/noise_level_embeddings.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/noise_level_embeddings.py). The denoising process integrates the atom-level cross-attention encoder and decoder for detailed atomic processing, along with a [`diffusion_transformer.Transformer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L128) from [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py) for token-level refinement. The [`sample`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py#L306) function in [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_head.py) orchestrates the iterative generation of structures from initial noise, applying rigid augmentations and following a specific noise schedule.

The underlying transformer components, detailed in [`/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py), provide adaptive mechanisms for normalization and initialization. Functions like [`adaptive_layernorm`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py#L32) and [`adaptive_zero_init`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py#L63) allow the network to dynamically adjust its operations based on contextual information. Both self-attention and cross-attention mechanisms are implemented with support for pair conditioning, using [`jax.nn.softmax`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/modules.py#L117) for attention weights and optional gating for information flow. The [`Transformer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py#L189) and [`CrossAttTransformer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/diffusion_transformer.py#L340) classes stack these components to build complex models, often leveraging [`hk.experimental.layer_stack`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/evoformer.py#L244) for managing deep networks.
