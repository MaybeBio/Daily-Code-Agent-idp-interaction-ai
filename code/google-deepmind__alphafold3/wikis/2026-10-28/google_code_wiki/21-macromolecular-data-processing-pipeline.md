### Macromolecular Data Processing Pipeline
The AlphaFold 3 model relies on a structured pipeline to convert raw macromolecular data, typically sourced from mmCIF files, into model-ready feature objects. This process, primarily managed by the [`WholePdbPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L86) class located in [`/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py), involves several stages: cleaning the input structures, identifying inter-chain bonds, tokenizing atoms, generating a variety of features, and finally padding the data for efficient batch processing.

The pipeline begins with a cleaning phase, where raw [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) objects are refined. This involves removing non-standard atoms, water molecules, and hydrogens. These operations ensure that the downstream model receives only relevant and standardized atomic information. This cleaning process is configured through various flags that allow for flexibility in how structures are prepared, such as enforcing covalent bonds or removing specific "leaving atoms" that might be part of glycan structures. This step uses functionalities within [`/google-deepmind/alphafold3/src/alphafold3/model/pipeline/structure_cleaning.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/structure_cleaning.py).

Following cleaning, the pipeline identifies and extracts inter-molecular bonds. This is crucial for understanding how different chains (e.g., polymers and ligands) interact within a complex. The system uses specific logic to differentiate between inter-residue bonds in ligands and inter-chain bonds in other contexts, allowing for precise identification of interactions such as polymer-ligand and ligand-ligand bonds. The identification process is handled by functions in [`/google-deepmind/alphafold3/src/alphafold3/model/pipeline/inter_chain_bonds.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/inter_chain_bonds.py), which supports filtering by chain type, residue name, and bond distance.

The cleaned and bond-identified structures are then subjected to atom tokenization. In this step, the atomic layout is converted into "tokens," which can represent residues or individual atoms, particularly for ligands. This tokenized representation is a fundamental unit for the downstream model's processing.

With the basic structural information prepared, the pipeline proceeds to generate a comprehensive set of features. This includes various feature types derived from the Multiple Sequence Alignments (MSAs) and structural templates, as well as atom-specific and token-specific features. Features related to inter-molecular bonds, pseudo-beta atom information, and structural frames are also computed. Each type of feature is generated by dedicated modules, contributing to the rich input representation required by AlphaFold 3. For further details on MSA and template generation, refer to [Input Feature Generation](#input-feature-generation).

Finally, to optimize model training and inference, the generated features are padded. This involves adjusting the size of the input data to fit predefined buckets, ensuring that batches of data have consistent dimensions. This padding mechanism minimizes computational overhead by reducing the need for dynamic memory allocation and frequent model recompilations during batch processing.
