### Structural Alignment and RMSD Calculation
The AlphaFold 3 model repository includes functionalities for structural alignment and calculating Root Mean Square Deviation (RMSD) between predicted and reference molecular structures. These tools, primarily found in [`/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py), are essential for evaluating the accuracy of predicted structures.

The process of structural alignment begins with [`transform_ls`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py#L25), which computes a least-squares best-fit rotation matrix. This matrix optimally superimposes one set of 3D coordinates onto another. It achieves this by using Singular Value Decomposition (SVD), a numerical method for factoring matrices, to find the rotation that minimizes the squared differences between corresponding points. The alignment operation, performed by [`align`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L68), then applies this calculated transformation to a target set of coordinates, rigidly moving it into the coordinate space of a reference structure.

After alignment, the [`deviations_from_coords`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py#L105) function quantifies the per-atom differences by calculating the Euclidean distance between the aligned coordinates and the ground truth coordinates. This provides a detailed view of where the predicted structure deviates from the reference. Finally, [`rmsd_from_coords`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py#L134) consolidates these per-atom deviations into a single metric, the Root Mean Square Deviation (RMSD). RMSD is a widely used measure in structural biology to quantify the average distance between the atoms of superimposed molecules, providing a comprehensive assessment of the structural similarity between a predicted model and its known reference.
