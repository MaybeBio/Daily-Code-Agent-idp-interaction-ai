### Efficient FASTA Iterators
The AlphaFold 3 codebase includes C++ implementations for memory-efficient FASTA parsing, designed to handle large datasets effectively. These implementations, located in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp), provide iterator-based parsing from both files and in-memory strings, enabling lazy iteration over FASTA records. This approach avoids loading entire files into memory, which is beneficial for processing extensive sequence databases.

The core functionalities are encapsulated in the [`FastaFileIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L20) and [`FastaStringIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L25) classes, defined in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_lib.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_lib.h) and implemented in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_lib.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_lib.cc). The [`FastaFileIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L20) facilitates sequential reading of sequence and description pairs from a specified FASTA file path, managing file streams incrementally. Similarly, the [`FastaStringIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L25) provides iterative parsing from an [`absl::string_view`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/mkdssp_pybind.cc#L44), which is useful when FASTA data is already loaded as a large string in memory. Both iterators maintain internal state to track parsing progress and yield each FASTA entry as it is processed.

To integrate these C++ efficiencies with the Python environment, [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148) bindings are provided in [`/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_pybind.cc). These bindings expose the [`FastaFileIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L20) and [`FastaStringIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L25) as Python iterator classes, allowing Python code to seamlessly iterate over FASTA records. The [`__next__`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator.pyi#L23) method within these Python-bound iterators includes Global Interpreter Lock (GIL) release mechanisms ([`py::gil_scoped_release`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/cif_dict_pybind.cc#L393)), which permit other Python threads to execute concurrently during compute-intensive C++ parsing operations, thus enhancing overall application responsiveness. For in-memory string iteration, the [`PythonFastaStringIterator`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/fasta_iterator_pybind.cc#L82) ensures the underlying string's lifetime is managed correctly to prevent data corruption. Additionally, general utilities for parsing entire FASTA strings into lists of sequences or sequence-description pairs are also exposed for convenience when full string parsing is acceptable. For more details on the C++/Python bindings, refer to [C++/Python Bindings and Performance](#data-parsing-and-preprocessing-cpython-bindings-and-performance).
