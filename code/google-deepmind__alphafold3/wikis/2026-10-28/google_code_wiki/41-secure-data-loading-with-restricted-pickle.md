### Secure Data Loading with Restricted Pickle
The [`safe_pickle`](https://github.com/google-deepmind/alphafold3/src/alphafold3/constants/chemical_components.py#L28) module provides a secure mechanism for loading trusted, pickled constant data. This module is designed to prevent arbitrary code execution, a common security vulnerability associated with [`pickle`](https://github.com/google-deepmind/alphafold3/run_alphafold_test.py#L29) when processing untrusted data. It implements this by strictly limiting the types of objects that can be unpickled.

The core of this security mechanism is the [`_RestrictedUnpickler`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L51) class, which overrides the standard [`pickle.Unpickler`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L51)'s [`find_class`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L54) method. This override ensures that only a predefined allowlist of built-in, innocuous types—such as [`NoneType`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/base_config.py#L37), [`bool`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L444), [`bytes`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L71), [`dict`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/cif_dict_lib.h#L125), [`float`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L32), [`frozenset`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L54), [`int`](https://github.com/google-deepmind/alphafold3/docs/input.md#L142), [`list`](https://github.com/google-deepmind/alphafold3/README.md#L75), [`set`](https://github.com/google-deepmind/alphafold3/README.md#L22), [`str`](https://github.com/google-deepmind/alphafold3/docs/input.md#L140), and [`tuple`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L1076)—can be successfully unpickled. Any attempt to load an object of a type not present in this [`_ALLOWED_BUILTINS`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L36) allowlist results in a [`pickle.UnpicklingError`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L58), thereby preventing the deserialization of potentially malicious objects.

The module offers a straightforward [`load`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L61) function as its main public interface. This function takes a file-like object and uses [`_RestrictedUnpickler`](https://github.com/google-deepmind/alphafold3/src/alphafold3/common/safe_pickle.py#L51) to safely deserialize the pickled data, enforcing the type restrictions. This approach ensures that only data structures and basic types that are inherently safe and cannot execute arbitrary code are processed, protecting the system from security exploits when loading pre-computed or static data distributed with the repository. For other common utilities, see [Common Utilities and Constants](#common-utilities-and-constants).
