### Struct-of-Arrays Design for JAX Compatibility
AlphaFold 3 leverages a "Struct-of-Arrays" (SoA) design pattern for its JAX-compatible geometric primitives, which optimizes performance by treating collections of geometric entities as arrays of components rather than arrays of objects. This design is critical for efficient batch operations, array-like indexing, and seamless integration with JAX's automatic differentiation and compilation capabilities.

The [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry) directory defines the core components implementing this pattern. Central to this is the [`StructOfArray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py#L199) decorator, found in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py). This decorator transforms standard Python [`dataclasses`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L33) into JAX-compatible structures that behave like "structs of arrays." When applied to a dataclass, it injects array-like behaviors such as slicing ([`__getitem__`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py#L178)), length ([`__len__`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py#L128)), and properties for [`shape`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L190) and [`dtype`](https://github.com/google-deepmind/alphafold3/docs/output.md#L25). Importantly, it registers the decorated dataclass as a JAX pytree node, allowing JAX transformations like [`jax.vmap`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/network/featurization.py#L47) and [`jax.jit`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L488) to operate smoothly on these structures. It also enforces shape and data type consistency across the internal arrays, ensuring data integrity within the SoA.

Key geometric structures like [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) (3D vectors), [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) (3D rotation matrices), and [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) (rigid transformations combining rotation and translation) are built upon this [`StructOfArray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py#L199) pattern.

*   The [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py), represents 3D vectors by storing their [`x`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L51), [`y`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L52), and [`z`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L53) components as separate JAX arrays. This enables optimized element-wise arithmetic operations and geometric calculations such as dot products, cross products, and norm computations.
*   The [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) class, implemented in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py), manages 3D rotation matrices. It stores the nine components of the matrix as individual JAX arrays, facilitating efficient operations like inversion, application to points, and composition of rotations. It also supports robust construction methods, including those based on Singular Value Decomposition (SVD) for numerical stability.
*   The [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) class, located in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py), encapsulates a 3D rigid transformation by combining a [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) for rotation and a [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) for translation. This class supports operations such as transformation composition, inversion, and the application of transformations to points. A notable feature is its ability to compute the optimal rigid transformation for aligning one set of points to another, which is fundamental for structural alignment tasks.

This consistent application of the SoA design ensures that all these geometric primitives benefit from JAX's performance optimizations, making them suitable for high-throughput computations in machine learning models like AlphaFold 3. The main types and functions from these modules are aggregated and re-exported through [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/__init__.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/__init__.py), providing a unified and convenient interface for their use.
