### Performance-Critical C++ Implementations (Pybind11)
The [`cpp`](https://github.com/google-deepmind/alphafold3/README.md#L139) subdirectory within the [`structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L306) module provides C++ implementations, exposed via [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148), for performance-critical operations involved in processing and managing molecular structure data. These functionalities are crucial for handling large [`mmCIF`](https://github.com/google-deepmind/alphafold3/docs/input.md#L38) files efficiently and preparing data for downstream modeling tasks.

One key area is the efficient management of structural hierarchy. The [`MmcifLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout.h#L37) class in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout.h) and [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_lib.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_lib.cc) parses the [`_atom_site`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/mmcif.py#L140) records of an [`mmCIF`](https://github.com/google-deepmind/alphafold3/docs/input.md#L38) file to provide a structured view of models, chains, residues, and atoms. This layout allows for quick identification of atom and residue ranges for specific chains, and its C++ implementation ensures that queries on the structural organization are performed with optimal speed. The [`MmcifLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout.h#L37) can also be filtered to retain only specific residues, and it can be constructed from [`CifDict`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/cif_dict.pyi#L26) objects, with robust error handling for inconsistent or malformed data. The Python bindings for [`MmcifLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout.h#L37) are provided in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_pybind.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_pybind.h) and [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_layout_pybind.cc), allowing Python users to leverage this efficient data structure for structural queries.

Another critical function is the resolution of alternate locations (alt-locs) in [`mmCIF`](https://github.com/google-deepmind/alphafold3/docs/input.md#L38) data. The [`ResolveMmcifAltLocs`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_altlocs.h#L49) function, implemented in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_altlocs.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_altlocs.h) and [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_altlocs.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_altlocs.cc), ensures that each atom has a unique spatial representation by selecting the most appropriate atom record when multiple alt-locs are present. This process prioritizes higher occupancy and uses alphabetical order for tie-breaking, ensuring a deterministic and chemically sensible selection. This functionality is essential for preparing clean, unambiguous structural data.

Efficient array operations are also vital for performance. The [`cpp`](https://github.com/google-deepmind/alphafold3/README.md#L139) directory includes optimized C++ implementations for common NumPy array manipulations, particularly for arrays containing Python objects and strings. For instance, the [`IsIn`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership_pybind.cc#L35) function in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership_pybind.cc) offers an O(N) complexity for membership testing, which is faster than NumPy's [`np.isin`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L978) for large datasets. Similarly, [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.cc) provides [`RemapNumpyArrayObjects`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.cc#L50) for remapping array elements based on a dictionary, [`FormatFloatArray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.cc#L140) for efficient float-to-string conversion, and [`RemapMultipleArrays`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.cc#L183) for consolidating data from multiple arrays. These C++ implementations, exposed through [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148) ([`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership_pybind.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership_pybind.h), [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/string_array_pybind.h)), minimize Python overhead and accelerate data preprocessing.

The extraction of bond information from [`mmCIF`](https://github.com/google-deepmind/alphafold3/docs/input.md#L38) files is handled by [`GetBondAtomIndices`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn.h#L37) in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn.h) and [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_lib.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_lib.cc). This function parses the [`_struct_conn`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/mmcif.py#L144) table to identify bonds and maps them to 0-based atom indices within the [`_atom_site`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/mmcif.py#L140) table. It also includes specific workarounds for known PDB data anomalies, ensuring robust bond extraction even from imperfect data. The Python binding ([`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_pybind.h`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_pybind.h), [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_struct_conn_pybind.cc)) allows Python code to retrieve this critical connectivity information.

Finally, the [`mmcif_utils`](https://github.com/google-deepmind/alphafold3/src/alphafold3/cpp.cc#L46) in [`/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_utils_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/mmcif_utils_pybind.cc) provides further Python bindings for C++ utilities that process and manipulate [`mmCIF`](https://github.com/google-deepmind/alphafold3/docs/input.md#L38) structural data. This includes functions for filtering atoms based on entity types (e.g., nucleotides, ligands, water) and for applying in-place corrections to residue-specific atom properties, such as fixing Arginine residues. These utilities help in cleaning and standardizing input data before it is fed into the AlphaFold 3 model.
