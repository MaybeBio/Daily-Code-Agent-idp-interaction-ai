#### Atom Layout and Feature Generation
Atomic and residue information is managed and transformed into [`AtomLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L45) objects as a foundational step in preparing input for the AlphaFold 3 model. This process begins with the [`WholePdbPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L86) which tokenizes the cleaned structural data. Tokenization, influenced by configuration options such as [`max_atoms_per_token`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L141) and [`flatten_non_standard_residues`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L155), converts the atom layout into the basic units (e.g., residues or individual ligand atoms) that the model processes.

The [`AtomLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L45) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py), serves as a structured representation for atom-level properties, storing details such as [`atom_name`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L570), [`res_id`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L544), and [`chain_id`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L534). Similarly, the [`Residues`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L214) dataclass, also in [`/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py), holds residue-level metadata like [`res_name`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L548) and [`chain_type`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L539). These dataclasses ensure immutability and consistency, providing a reliable foundation for downstream operations. The [`/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py) module also provides utility functions to convert raw [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) objects into [`AtomLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L45) and [`Residues`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L214) instances, inferring details like termini and deprotonation states. This includes a robust mechanism for generating a flat [`AtomLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L45) from [`Residues`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L214) objects, optionally incorporating hydrogens and handling unknown residues using chemical component definitions and RDKit utilities for SMILES-based atom generation.

Following this initial structuring, various feature modules generate model inputs. These include features for [`AtomCrossAtt`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L1910), [`TokenFeatures`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L905), [`MSA`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L412), [`Templates`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L719), and bond information, all coordinated by the [`WholePdbPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L86). For instance, [`MSA.compute_features`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L339) handles multiple sequence alignment data, while [`Templates.compute_features`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L351) processes structural templates. Information regarding polymer-ligand and ligand-ligand bonds is generated by dedicated features within the pipeline. Each feature module is responsible for computing a specific set of inputs for the model.

Finally, all generated features are padded to uniform sizes and assembled into a [`feat_batch.Batch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L80) object. This padding, managed by the [`calculate_bucket_size`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/pipeline/pipeline.py#L43) function within the pipeline, is crucial for efficient batch processing and memory management during model inference and training. The [`GatherInfo`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L314) dataclass and its associated [`compute_gather_idxs`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L894) and [`convert`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/confidence_types.py#L218) functions are used to efficiently remap and transform data between different [`AtomLayout`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/atom_layout/atom_layout.py#L45) representations. This ensures data consistency and optimal performance as features are passed through the model.
