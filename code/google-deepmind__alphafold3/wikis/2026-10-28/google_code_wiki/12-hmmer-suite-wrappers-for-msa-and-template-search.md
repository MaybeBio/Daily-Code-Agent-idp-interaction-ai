### HMMER Suite Wrappers for MSA and Template Search
Python wrappers provide an interface to the HMMER suite of tools, which are used for sequence and profile-based searches against biological sequence databases. These wrappers standardize interactions with various Multiple Sequence Alignment (MSA) tools and manage searches against sharded databases. The common interface for these tools is defined by the [`MsaTool`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py#L44) protocol and the [`MsaToolResult`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py#L27) dataclass in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py).

The [`Hmmbuild`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py#L31) class in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py) provides a wrapper for the [`hmmbuild`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py#L31) binary. It constructs HMM profiles from MSAs provided in Stockholm or A3M formats. For A3M input, it preprocesses the MSA by removing inserted residues to convert it into an aligned FASTA format before profile construction.

The [`Hmmalign`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L37) class in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py) wraps the [`hmmalign`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L37) binary to align sequences to an HMM profile. It handles input sequences in A3M format and preprocesses them by removing gaps and converting to uppercase to prepare them for alignment.

For searching sequence databases with HMM profiles, the [`Hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) class in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py) wraps the [`hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) binary. It supports querying directly with a pre-built HMM or by first building an HMM from an A3M or Stockholm MSA using an internal [`hmmbuild`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py#L31) instance. The output from [`hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) (in Stockholm format) is converted to A3M format.

The [`Jackhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py#L37) class in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py) provides a wrapper for the [`jackhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py#L37) binary. It performs iterative sequence searches against protein sequence databases and generates MSAs. It supports sharded databases, executing queries in parallel across shards and merging results based on e-values and bit scores. Result merging is an important aspect of managing sharded databases, ensuring that top hits are consistently identified across all shards.

Similarly, the [`Nhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py#L43) class in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py) wraps the [`Nhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py#L43) binary for searching nucleotide sequence databases. Like [`Jackhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py#L37), it supports sharded databases, using parallel execution for shards and merging results. It also includes post-processing steps using [`Hmmalign`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L37) and [`Hmmbuild`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py#L31) to ensure MSA width consistency with the query sequence. Special handling is implemented for short RNA sequences by adjusting parameters.

Throughout these wrappers, temporary files are used for input and output. External command execution, logging, and error management are handled by functions such as [`run`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/subprocess_utils.py#L67), ensuring robust interaction with the underlying HMMER binaries. For managing sharded database paths, the [`shards`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L54) module in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/shards.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/shards.py) provides utilities to parse shard specifications and generate lists of sharded file paths.
