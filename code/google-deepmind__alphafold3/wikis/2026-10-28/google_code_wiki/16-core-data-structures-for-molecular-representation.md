### Core Data Structures for Molecular Representation
The molecular structure management in AlphaFold 3 centers around a robust, immutable data model designed for efficiency and consistency. The [`Structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L306) class, defined in [`/google-deepmind/alphafold3/src/alphafold3/structure/structure.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py), serves as the primary representation of a molecular entity. It aggregates data for chains, residues, atoms, and bonds, storing them as instances of specialized [`dataclasses`](https://github.com/google-deepmind/alphafold3/run_alphafold.py#L33): [`Chains`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L114), [`Residues`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L214), [`Atoms`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py#L89) (from [`/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure_tables.py)), and [`Bonds`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/bonds.py#L33) (from [`/google-deepmind/alphafold3/src/alphafold3/structure/bonds.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/bonds.py)). These dataclasses extend a common [`Table`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py#L58) base class, implemented in [`/google-deepmind/alphafold3/src/alphafold3/structure/table.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py).

The [`Table`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py#L58) base class provides a dataclass-based, immutable structure that underpins the storage of structural data. Each [`Table`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/table.py#L58) instance manages columns of equal length, identified by a unique [`key`](https://github.com/google-deepmind/alphafold3/src/alphafold3/parsers/cpp/cif_dict_lib.cc#L322), with all data columns backed by [`numpy.ndarray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership.pyi#L24) objects. This [`numpy.ndarray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership.pyi#L24) backend is crucial for enabling efficient, vectorized operations across the structural data. The design emphasizes immutability; any operation that conceptually "modifies" a [`Structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L306) or its constituent tables actually returns a *new* instance with the desired changes, promoting predictable behavior and simplifying data integrity.

Data consistency is maintained through several mechanisms. The [`Structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L306) class enforces foreign key relationships between its internal tables, ensuring that, for example, an atom always belongs to an existing residue, and a residue to an existing chain. This relational integrity is validated during object construction using [`_validate_table_foreign_keys`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L355). Furthermore, the [`_cascade_delete`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L1426) mechanism within the [`Structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/structure.py#L306) class ensures that when a higher-level entity (like a residue) is removed, all its dependent lower-level entities (like its atoms) are also appropriately handled, preventing orphaned records and maintaining structural coherence. This immutable, table-based design, coupled with [`numpy.ndarray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure/cpp/membership.pyi#L24) for core data storage, provides a powerful and efficient framework for representing and manipulating molecular structures within AlphaFold 3. The [`/google-deepmind/alphafold3/src/alphafold3/structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/structure) directory provides a consolidated interface for accessing these core structural components.
