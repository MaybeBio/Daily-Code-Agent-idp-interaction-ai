## Geometric Primitives and Operations
The AlphaFold 3 codebase includes a dedicated module for JAX-compatible geometric primitives, operations, and utilities. This module, found under [`/google-deepmind/alphafold3/src/alphafold3/jax`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax), is designed to handle 3D vectors, rotation matrices, and rigid transformations using a "struct-of-arrays" design. This approach optimizes performance within JAX, facilitating efficient batch operations and seamless integration with JAX's automatic differentiation and compilation capabilities.

Central to this module are the [`Vec3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L38) for 3D vectors, [`Rot3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rotation_matrix.py#L118) for 3D rotation matrices, and [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) for rigid transformations, which combine rotation and translation. These classes support fundamental geometric operations such as vector arithmetic (addition, subtraction, multiplication, division), cross and dot products, and norm calculations. For rotations, functionalities include inversion, application to points, and composition. The [`Rigid3Array`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/rigid_matrix_vector.py#L109) further allows for the composition of transformations, inversion, and the application of transformations to points. A key capability is the ability to compute optimal rigid transformations for aligning point sets, which is crucial for structural superposition tasks.

The "struct-of-arrays" design, implemented via the [`StructOfArray`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py#L199) decorator from [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/struct_of_array.py), ensures that these geometric objects are efficient for JAX computations. This design stores components (e.g., x, y, z coordinates of a vector, or individual elements of a rotation matrix) in separate arrays rather than as structures within a single array. This avoids potential performance bottlenecks and precision issues that can arise in high-performance computing environments, especially with mixed-precision operations.

Beyond core transformations, the module provides utilities for calculating distances, such as [`square_euclidean_distance`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L142) and [`euclidean_distance`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L180), and angular measurements like [`dihedral_angle`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L200) for torsion angles. It also includes functions for robust weighted means, [`weighted_mean`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/confidences.py#L239) in [`/google-deepmind/alphafold3/src/alphafold3/jax/geometry/utils.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/utils.py), which prevent numerical instability when dealing with zero sums in weights. The [`alphafold3.jax.geometry`](https://github.com/google-deepmind/alphafold3/src/alphafold3/jax/geometry/vector.py#L25) module serves as a unified access point for these functionalities, simplifying their use throughout the AlphaFold 3 codebase.
