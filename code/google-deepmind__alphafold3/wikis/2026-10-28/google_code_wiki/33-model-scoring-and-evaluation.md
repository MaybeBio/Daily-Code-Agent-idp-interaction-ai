## Model Scoring and Evaluation
Molecular structures predicted by AlphaFold 3 are scored and evaluated using a suite of tools that perform structural alignment, calculate RMSD, detect and compare chirality, and generate pseudo-beta atom positions. These functions are primarily located within the [`/google-deepmind/alphafold3/src/alphafold3/model/scoring`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring) directory.

Structural alignment and Root Mean Square Deviation (RMSD) calculations are performed to quantify differences between predicted and ground truth structures. The [`align`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L68) function in [`/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/alignment.py) aligns two sets of 3D coordinates by computing a least squares best-fit rotation matrix, which can then be used to calculate per-atom deviations and the overall RMSD between the structures. This is a common method for evaluating the global similarity of molecular models.

For ligand molecules, chirality detection and comparison are critical for assessing the stereochemical correctness of predictions. The [`compare_chirality`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py#L149) function in [`/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/chirality.py) identifies chiral centers within a ligand structure and compares them against reference molecules or entries from the Chemical Components Dictionary (CCD). This process involves converting [`structure.Structure`](https://github.com/google-deepmind/alphafold3/run_alphafold_data_test.py#L88) objects to RDKit [`Mol`](https://github.com/google-deepmind/alphafold3/docs/input.md#L796) objects and then applying RDKit's stereochemistry functionalities.

Pseudo-beta atom positions are generated as a simplified representation of molecular structures, particularly useful for quality assessment. The [`pseudo_beta_fn`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/scoring.py#L30) function in [`/google-deepmind/alphafold3/src/alphafold3/model/scoring/scoring.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/scoring/scoring.py) computes these positions from full atomic data, supporting both JAX and NumPy backends. This abstraction helps in evaluating model quality without needing to consider every atom, streamlining downstream analysis.
