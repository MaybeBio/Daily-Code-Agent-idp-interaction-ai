## Setup and Environment Configuration
The AlphaFold 3 environment setup is primarily managed through Docker, which orchestrates the installation of system dependencies, Python packages, HMMER, and crucial configurations for XLA optimization on GPUs. This ensures a consistent and reproducible development and runtime environment. Complementary scripts are provided for efficient management of Solid State Drives (SSDs), particularly for handling large public databases within cloud environments.

The core of the environment setup involves building a Docker image as defined in [`/google-deepmind/alphafold3/docker/Dockerfile`](https://github.com/google-deepmind/alphafold3/docker/Dockerfile). This process starts from an [`nvidia/cuda`](https://github.com/google-deepmind/alphafold3/docker/Dockerfile#L20) base image, which provides CUDA compatibility essential for GPU acceleration. System dependencies such as Python 3.12, [`git`](https://github.com/google-deepmind/alphafold3/CMakeLists.txt#L22), [`gcc`](https://github.com/google-deepmind/alphafold3/docker/Dockerfile#L25), and [`make`](https://github.com/google-deepmind/alphafold3/LICENSE#L77) are installed, followed by the [`uv`](https://github.com/google-deepmind/alphafold3/pyproject.toml#L42) package manager. [`uv`](https://github.com/google-deepmind/alphafold3/pyproject.toml#L42) is configured to create an isolated Python virtual environment and manage AlphaFold 3's Python dependencies in a frozen and reproducible manner. HMMER version 3.4 is compiled and installed from source, including a specific patch for [`jackhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py#L37), highlighting the need for precise version control and customized behavior for key bioinformatics tools. The Dockerfile also integrates the AlphaFold 3 source code and executes a [`build_data`](https://github.com/google-deepmind/alphafold3/src/alphafold3/build_data.py#L32) script to construct necessary chemical components databases. For GPU performance optimization, XLA environment variables are explicitly configured to manage memory preallocation and general behavior, particularly for high-performance GPUs like the A100. For more detailed information on the Docker build process, refer to [Docker Image Build and Environment Setup](#setup-and-environment-configuration-docker-image-build-and-environment-setup).

Beyond the Docker image, the repository includes shell scripts in [`/google-deepmind/alphafold3/src/alphafold3/scripts`](https://github.com/google-deepmind/alphafold3/src/alphafold3/scripts) to manage SSDs, particularly in cloud computing contexts like Google Cloud Platform (GCP). The [`/google-deepmind/alphafold3/src/alphafold3/scripts/gcp_mount_ssd.sh`](https://github.com/google-deepmind/alphafold3/src/alphafold3/scripts/gcp_mount_ssd.sh) script automates the process of identifying, formatting (if necessary, using [`mkfs.ext4`](https://github.com/google-deepmind/alphafold3/src/alphafold3/scripts/gcp_mount_ssd.sh#L35)), and mounting local SSDs to a specified directory, ensuring they are ready for use. Following this, the [`/google-deepmind/alphafold3/src/alphafold3/scripts/copy_to_ssd.sh`](https://github.com/google-deepmind/alphafold3/src/alphafold3/scripts/copy_to_ssd.sh) script handles the transfer of large public database files to the mounted SSD. This script intelligently manages disk space by calculating the total size of files to be copied against available space and prioritizes transfers, iteratively removing less critical files if space is insufficient. This ensures that the most essential databases are moved first, optimizing data access for AlphaFold 3's operations. Further details on SSD management are available in [SSD Management for Database Storage](#setup-and-environment-configuration-ssd-management-for-database-storage).
