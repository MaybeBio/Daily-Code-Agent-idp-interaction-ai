## Input Feature Generation
The AlphaFold 3 model relies on a comprehensive process to transform raw biological data into a structured set of input features. This process involves generating Multiple Sequence Alignments (MSAs), identifying and extracting structural templates, and managing the overall representation of biological macromolecules. The system integrates both efficient C++ implementations and Python wrappers for external tools to achieve this.

The core of this feature generation is managed by the data processing utilities located in the [`/google-deepmind/alphafold3/src/alphafold3/data`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data) directory. The primary entry point for this process is [`featurise_input`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py#L47) in [`/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/featurisation.py), which validates input data and orchestrates its transformation into [`BatchDict`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L52) objects suitable for model consumption. This function leverages the [`DataPipeline`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L304) class defined in [`/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py) to manage the complex sequence of steps, including MSA and template generation. The pipeline utilizes a [`ThreadPoolExecutor`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/model.py#L479) for parallel execution of computationally intensive tasks, allowing multiple MSA and template searches to run concurrently. To prevent redundant computations for identical sequences, especially in complexes with multiple identical chains, [`functools.cache`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/pipeline.py#L39) is used on certain pipeline steps.

Multiple Sequence Alignment (MSA) data is managed by the [`Msa`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py#L61) class in [`/google-deepmind/alphafold3/src/alphafold3/data/msa.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa.py). This class provides mechanisms for parsing MSAs from various formats (e.g., A3M), deduplicating sequences to ensure uniqueness, and converting raw MSA data into numerical features that capture sequence variability and deletions. The extraction of specific species identifiers from UniProtKB-formatted MSA descriptions is handled by [`get_identifiers`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py#L88) in [`/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/msa_identifiers.py). For performance-critical computations, such as calculating MSA profiles (residue frequencies at each position), C++ implementations are used, specifically [`ComputeMsaProfile`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc#L31) in [`/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/cpp/msa_profile_pybind.cc), which is exposed to Python via [`pybind11`](https://github.com/google-deepmind/alphafold3/README.md#L148).

The system also integrates various external tools from the HMMER suite through Python wrappers found in [`/google-deepmind/alphafold3/src/alphafold3/data/tools`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools). These wrappers standardize the interaction with tools like [`Jackhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py#L37) (for protein sequence searches, [`/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/jackhmmer.py)), [`Nhmmer`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py#L43) (for nucleotide sequence searches, [`/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/nhmmer.py)), [`Hmmsearch`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py#L31) (for database searches with HMM profiles, [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmsearch.py)), [`Hmmbuild`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py#L31) (for building HMM profiles, [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmbuild.py)), and [`Hmmalign`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py#L37) (for aligning sequences to HMM profiles, [`/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/hmmalign.py)). These wrappers handle details such as sharded database searches, temporary file management, and consistent parsing of tool outputs, abstracting away the complexities of command-line execution. An [`MsaTool`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py#L44) protocol in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/msa_tool.py) provides a standardized interface for all MSA tools.

Structural template handling is managed by the [`Templates`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L719) class in [`/google-deepmind/alphafold3/src/alphafold3/data/templates.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/templates.py). This class collects potential structural matches (hits) from searches, filters them based on various criteria (e.g., release date, alignment quality, sequence identity), and then featurizes them into model-ready inputs. A notable aspect of template processing is the [`realign_hit_to_structure`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py#L29) function in [`/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/template_realign.py), which addresses discrepancies between sequences obtained from template search tools (often derived from PDB SEQRES records) and the actual sequences in mmCIF structures, ensuring accurate mapping for feature generation. Structures are retrieved from various sources using the [`StructureStore`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/structure_stores.py#L32) in [`/google-deepmind/alphafold3/src/alphafold3/data/structure_stores.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/structure_stores.py), which supports in-memory mappings, tar archives, or filesystem directories.

For handling molecular data beyond proteins and nucleic acids, particularly ligands, the [`rdkit_utils`](https://github.com/google-deepmind/alphafold3/src/alphafold3/model/features.py#L38) in [`/google-deepmind/alphafold3/src/alphafold3/data/tools/rdkit_utils.py`](https://github.com/google-deepmind/alphafold3/src/alphafold3/data/tools/rdkit_utils.py) provides utilities for converting molecular data between RDKit [`Mol`](https://github.com/google-deepmind/alphafold3/docs/input.md#L796) objects and CCD-like mmCIF dictionaries. This includes parsing atom and bond data, populating molecular structures, and generating 3D conformers for molecules, which are essential for ligand featurization. This integration ensures that the AlphaFold 3 model can process a diverse range of biological entities. For a detailed discussion on how these features are consumed by the model, see [Core Model Architecture and Pipeline](#core-model-architecture-and-pipeline).
