When writing code, please try to be as frugal as possible. keep your changes and edits minimal so as to fulfill the required objective, but pay close attention to well-written, compact and readable code. avoid code bloat, unnecessary helper functions, inelegant structure, and don't hesitate to suggest design decisions at a higher level than the given task that could save lines of code, or making things more reusable instead of copying logic. try to follow the conventions and coding style of the existing repository as much as you can.

Also, ALWAYS run the full test suite AFTER completing a major implementation, but NEVER run the full test suite while doing the implementation. Only run the full test suite after having iterated on the unit tests in dedicated files. The full test suite is large and expensive and will slow down your iterations by a huge factor. It should only be run to check global consistency and backward compatibility at the end of an implementation phase.
